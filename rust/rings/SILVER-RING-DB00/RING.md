# RING.md — SILVER-RING-DB00

## Metal
Silver

## Package
trios-mb-db

## Purpose
PostgreSQL/Supabase database adapter using sea-orm. Implements `trios-mb-traits::Database`.

## Dependencies (internal)
- trios-mb-types (GOLD)
- trios-mb-traits (GOLD)

## API Surface
- `pub struct PostgresDatabase` — concrete impl of Database trait
- `pub async fn connect(url: &str) -> Result<PostgresDatabase>`
- `pub async fn run_migrations(conn: &DatabaseConnection)`
- Entity modules generated by sea-orm

## Build
```bash
cargo build -p trios-mb-db
cargo test -p trios-mb-db
```
