## 🔍 Что смотреть в логах

После теста смотрите логи на сервере:

```bash
ssh root@188.137.250.69 'docker logs 999-multibots --tail 200 -f | grep -E "tokenChars|tokenTrimLength|DIAGNOSTIC|replicate.run|hasToken"'
```

### Ожидаемые логи:

```json
{
  "message": "🔍 [DIRECT] Определяем API провайдер для модели",
  "api_type": "replicate",  // <-- Должно быть "replicate"!
  "model_url": "ghashtag/neuro_coder_flux-dev-lora:5ff9e...",
}

{
  "message": "[DIAGNOSTIC] Проверка токена перед replicate.run()",
  "hasToken": true,         // <-- Должно быть true!
  "tokenLength": 40,        // <-- Должно быть 40!
  "tokenPreview": "r8_BcAdO3L...",
  "tokenChars": "0:114,1:56,2:56,3:95,...",  // <-- Все коды символов
  "tokenTrimLength": 40,    // <-- Должно совпадать с tokenLength!
}
```

### Если tokenTrimLength < tokenLength:
**ПРОБЛЕМА**: В токене есть пробелы или невидимые символы
**РЕШЕНИЕ**: Очистить токен от лишних символов

### Если tokenChars показывает неожиданные коды:
**ПРОБЛЕМА**: Токен содержит неправильные символы
**РЕШЕНИЕ**: Проверить, что в Infisical сохранен правильный токен
