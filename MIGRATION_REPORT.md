### ✅ 2. Миграция neuroPhotoWizardV2
**Статус**: Завершено

#### Что сделано:
- ✅ Создан новый `index.ts` с Inngest логикой

- ✅ Добавлена отправка событий в Inngest
- ✅ Добавлена мгновенная обратная связь пользователю
- ✅ Добавлен статус трекинг
- ✅ Старый файл сохранён как `index_old.ts`

#### Ключевые изменения:

**ДО** (старая логика):
```typescript
// БЛОКИРУЮЩИЙ ВЫЗОВ - пользователь ждёт 5-10 секунд
await generateNeuroPhotoHybrid(
  fullPrompt,
  ctx.session.userModel.model_url as any,
  1,
  userId.toString(),
  ctx,
  ctx.botInfo?.username
)
await ctx.replyWithPhoto(result.imageUrl)  // Пользователь ждал!
```

**ПОСЛЕ** (новая логика):
```typescript
// НЕБЛОКИРУЮЩИЙ ВЫЗОВ - мгновенный ответ
const eventId = await sendInngestEvent(
  INNGEST_EVENTS.NEURO_IMAGE_GENERATION,
  {
    prompt: fullPrompt,
    modelUrl: ctx.session.userModel.model_url,
    userId: userId.toString(),
    telegramId: userId.toString(),
    metadata: { type: 'single-photo' },
  }
)

// Мгновенно отвечаем пользователю
await ctx.reply(
  `⏳ Создаю изображение...\n\nID задачи: ${eventId.substring(0, 8)}...`
)
```

#### Пользовательский опыт:

**ДО**:
1. Пользователь отправляет промпт
2. **Ждёт 5-10 секунд** ⏳
3. Получает изображение

**ПОСЛЕ**:
1. Пользователь отправляет промпт
2. **Мгновенно** получает: "⏳ Создаю изображение... ID: abc123..."
3. Может проверить статус кнопкой
4. Получает уведомление когда готово
