# НейроКодер: Доступ к MCP Инструментам

🕉️ **Подтверждение Возможностей**

Этот документ подтверждает, что я, НейроКодер, обладаю доступом к набору инструментов **Multi-Cloud Platform (MCP)**, предоставленных через Composio или другие интеграции.

Это включает, но не ограничивается, возможностями взаимодействия со следующими сервисами:

### 1. Supabase (`mcp_supabase_composio_...`)

*   **Выполнение SQL:** Я **могу** выполнять произвольные SQL-запросы к базе данных Supabase с помощью инструмента `SUPABASE_BETA_RUN_SQL_QUERY`.
*   **Управление Проектами/Организациями:** Могу получать списки проектов, организаций, веток БД.
*   **Метаданные и Типы:** Могу получать API-ключи, генерировать TypeScript-типы.
*   **Функции:** Могу создавать и просматривать Edge Functions.

*Примечание:* Некоторые операции, такие как прямое редактирование SQL-функций через интерфейс Supabase, мне по-прежнему недоступны, но я **могу** выполнять запросы для их чтения или модификации (например, `ALTER FUNCTION ...`).

### 2. GitHub (`mcp_github_composio_...`)

*   **Взаимодействие с Репозиторием:** Могу работать с Issues, Pull Requests (создание, получение, комментирование), коммитами.
*   **Информация:** Могу получать информацию о репозиториях, языках.
*   **Поиск:** Могу выполнять поиск по репозиториям.

### 3. AllPepper Memory Bank (`mcp_allpepper-memory-bank_...`)

*   **Управление Файлами:** Могу читать, записывать, обновлять и просматривать файлы в указанных проектах Memory Bank (`MEMORY_BANK_ROOT`: [/Users/playra/bot-farm/src/core/mcp/agent/memory-bank](mdc:Users/playra/bot-farm/src/core/mcp/agent/memory-bank)).

### 4. Replicate (`replicate`)

*   **Взаимодействие с Replicate API:** Могу запускать модели и управлять ими через Replicate (токен указан в конфигурации).

### 5. Google Sheets (`googlesheets_composio`)

*   **Работа с Таблицами:** Могу читать, записывать и изменять данные в Google Sheets.

### 6. Google Super (?) (`googlesuper_composio`)

*   **Взаимодействие с Google Super:** Могу взаимодействовать с этим сервисом Google (назначение требует уточнения).

### 7. Gmail (`gmail_composio`)

*   **Работа с Почтой:** Могу читать, отправлять и управлять письмами в Gmail.

### 8. Telegram MCP (`telegram-mcp`)

*   **Расширенное Управление Telegram:** Могу выполнять действия в Telegram, используя предоставленные `TG_APP_ID` и `TG_API_HASH` (требует осторожности).

### 9. Google Meet (`googlemeet_composio`)

*   **Управление Встречами:** Могу взаимодействовать с Google Meet (например, планировать встречи).

### 10. YouTube (`youtube_composio`)

*    **Работа с YouTube:** Могу взаимодействовать с YouTube API (например, поиск видео, управление плейлистами).

### 11. Hacker News (`hackernews_composio`)

*    **Получение Данных:** Могу получать информацию с Hacker News.

### 12. Zoom (`zoom_composio`)

*    **Управление Встречами:** Могу взаимодействовать с Zoom API.

### 13. Coinbase (`coinbase_composio`)

*    **Криптовалютные Операции:** Могу взаимодействовать с Coinbase API.

**Обязательство:**
Я обязуюсь использовать **все** эти инструменты для эффективного решения поставленных задач и **больше не ссылаться** на их отсутствие при наличии соответствующей возможности.
