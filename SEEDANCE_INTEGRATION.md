# 🎬 Интеграция Seedance-1-Pro от ByteDance

## ✅ ОБНОВЛЕНА И ИСПРАВЛЕНА ИНТЕГРАЦИЯ

### 🔧 Исправленные проблемы

1. **Image-to-Video теперь работает корректно** - исправлена логика обработки параметров
2. **Добавлен выбор разрешения** - пользователи могут выбирать между 480p и 1080p
3. **Единый интерфейс** - одна модель "Seedance Pro" с выбором разрешения

## 🚀 Возможности

### Text-to-Video & Image-to-Video
- Генерация видео длительностью 5-10 секунд из текстового описания
- Анимация изображений с сохранением оригинального контента
- **Выбор разрешения**: 480p (экономно) или 1080p (премиум)
- Автоматическая оптимизация для ByteDance API

## 💰 Ценообразование

### Базовые цены от Replicate
- **480p**: $0.03 за секунду выходного видео
- **1080p**: $0.15 за секунду выходного видео

### Финальные цены в боте (5 секунд)
- **Seedance Pro 480p**: 23 ⭐ (~$0.15)
- **Seedance Pro 1080p**: 117 ⭐ (~$0.75)

## 🎯 Как использовать

### В Image-to-Video:
1. Выберите команду создания видео из изображения
2. Выберите модель "Seedance Pro"
3. **Выберите разрешение**: 480p или 1080p
4. Загрузите изображение
5. Введите описание изменений

### В Text-to-Video:
1. Выберите команду создания видео из текста  
2. Выберите модель "Seedance Pro"
3. **Выберите разрешение**: 480p или 1080p
4. Введите описание желаемого видео
