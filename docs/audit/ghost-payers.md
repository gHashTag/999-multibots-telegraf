## Почему это не косметика

`updateUserBalance` устроена **несимметрично**:

- **списание** (`MONEY_OUTCOME`) при отсутствии профиля **проходит** — ошибка
  только пишется в лог;
- **пополнение** (`MONEY_INCOME`) при отсутствии профиля **отклоняется**:
  `.single()` по `users` не находит строку, функция возвращает `false`.

То есть потратить можно, а получить нельзя. И путь сюда ведёт прямо от вебхука
Robokassa (`inngest_app/functions/payments/paymentProcessing.ts:159`): человек
заплатил, деньги списаны платёжной системой, звёзды не зачислены.

Прежние сообщения в логе — «Пользователь не найден при создании транзакции» — не
давали этого понять: выглядело как обычная неудачная выборка.

## Что сделано

Только диагностика. Сообщение теперь называет вещи своими именами и содержит
`inv_id`, способ оплаты и сумму:

```
💸❌ Пополнение отклонено: профиля нет в users
   alert: ДЕНЬГИ ПОЛУЧЕНЫ, ЗВЁЗДЫ НЕ ЗАЧИСЛЕНЫ — нет профиля в users
```

По этой строке можно поставить оповещение и увидеть случай в тот же день, а не
через год при разборе данных.

**Семантику я не менял.** Создавать профиль по факту оплаты — продуктовое
решение: какой `bot_name` записать, какой язык, что делать с рефералами. Гадать
здесь нельзя.
