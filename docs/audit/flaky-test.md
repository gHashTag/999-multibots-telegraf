# Нестабильный тест: один, и уже не нестабильный

`npm run test:gate` в прошлой итерации сообщил: «нестабильных (со второго раза
зелёные): 1». Флак обесценивает проверку постепенно — если часть красного
считается шумом, «регрессий нет» перестаёт что-либо значить. Разобрал, пока
случай единственный.

## Причина

`src/__tests__/core/saveVideoUrlToSupabase.test.ts` ходил в сеть **по-настоящему**.

Он заглушал базу и журнал, но не зеркалирование. А `saveVideoUrlToSupabase`
зовёт `mirrorToOwnStorage`, который **скачивает файл** по адресу из аргумента:

```ts
const res = await fetch(sourceUrl, { signal: AbortSignal.timeout(60_000) })
```

Проверки проходили только потому, что `https://replicate.delivery/xezq/abc/out.mp4`
не существует, а зеркалирование по контракту при любой неудаче возвращает
исходную ссылку. То есть **тест зависел от того, что сеть откажет** — и
однажды она отказала иначе.

## Починка

Заглушка на `@/core/supabase/mirrorToStorage`. Время исполнения тестов в файле
упало с десятков миллисекунд ожидания сети до 4 мс. Зеркалирование проверяется
отдельно, в `src/__tests__/assets/mirror-storage.test.ts`.

## Перепись: кто ещё ходит в сеть

Чтобы не гадать, добавлен наблюдатель — `scripts/detect-network-tests.mjs`,
подключается только по `DETECT_NETWORK=1`:

```
npm run test:network
```

Результат на всём прогоне:

```
наблюдатель подключился к 181 файлам тестов
настоящих сетевых вызовов: 0
✅ Ни один тест не ходит в сеть.
```

Первая строка важнее второй: без неё «ноль вызовов» неотличимо от «наблюдатель
не подключился». Поэтому отчёт падает с ошибкой, если подключений ноль.

## Три раза подряд инструмент показал ноль, и трижды это было враньё

1. **Флаг `--setupFiles` не применялся.** Ноль вызовов.
2. **`console.log` из проходящих тестов vitest прячет.** Переписал в файл —
   снова ноль.
3. **Сам наблюдатель падал при загрузке**: обращение к константе до её
   объявления. Ноль.

Каждый раз ноль выглядел как хорошая новость. Отличить его от поломки удалось
только отметкой загрузки и обратной проверкой: снял заглушку — наблюдатель
показал 9 вызовов, вернул — ноль.

Это четвёртый случай за неделю, когда «ничего не найдено» оказывается «ничего
не искали». Правило записано в скилл ещё в понедельник — и я всё равно
наступил на него трижды за один час.

## Что проверено попутно

`npm run test:gate` прогнан три раза подряд — нестабильных больше нет.

Отдельно: в `src/__tests__/core/openai/requests.test.ts` шесть падающих
проверок. Сверено со снимком: те же шесть падали и до моих правок, в снимке
зелёными числятся другие шесть. Это давний долг, а не регрессия.
