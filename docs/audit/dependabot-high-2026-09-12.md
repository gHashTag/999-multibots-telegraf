## Уроки

- Сначала спросить «кто тянет уязвимый пакет» (`npm ls`, `cargo tree -i`), потом искать версию. Иногда ответ — совсем другая зависимость.
- Dependabot API отдаёт максимум 100 алертов на страницу, вторая страница возвращала 401 — считать через `gh api --paginate --slurp` и суммировать длины страниц.
- Замена библиотеки дешевле, чем кажется, если код использует 5–6 функций: шим держит старые вызовы, меняется только импорт и `await` (exceljs пишет асинхронно).
- `scripts/financial/*.js` подключают шим из `dist/` — им нужен `bun run build`. Это одноразовые скрипты с тестовыми ключами (см. OWNER-DECISIONS), в проде не запускаются.

## Что осталось и почему не закрыто

- `image-size` ≤ 2.0.2 (#488, #489): DoS в парсерах ICNS/JXL/HEIF. Патча нет ни в одной линии, `latest` = 2.0.2. Тянется через `metro` (бандлер React Native), работает только на dev-машине при сборке, парсит локальные ассеты. Убрать нельзя без отказа от Expo/RN. Вариант — dismiss в Dependabot как `tolerable_risk` с этой мотивировкой; решение за владельцем.
