# Обучение моделей перестало списывать деньги в ноябре 2025

## Одной строкой

Единственный зарегистрированный обработчик `model/training.start` —
`existing/generateModelTrainingFunction` — не содержит ни одного денежного
вызова; списание осталось только в незарегистрированной копии. С ноября 2025
все обучения бесплатны, четыре из них — у живых людей.

## Как нашлось

Луп по долгу «выброшенный результат денежной операции» привёл в
`training/generateModelTraining.ts`. По привычке из
`vibee-stack-hard-won` («правка в файле, который никто не исполняет»)
проверил регистрацию — файл оказался мёртвой копией (это уже было известно:
`registration.test.ts`, PR #507). Новым оказалось другое: в ЖИВОМ файле
денег нет вообще.

```
grep -c "updateUserBalance\|processBalanceOperation\|directPaymentProcessor" \
  src/inngest_app/functions/existing/generateModelTrainingFunction.ts   # 0
```

Отправляющая сцена `uploadTrainFluxModelScene` тоже не списывает.

## Горькая симметрия

Июль 2025: @Ludmila заплатила пять раз и не получила ни одной модели
(вебхук бил в 404). Ноябрь 2025 и дальше: люди получают модели и не платят
ничего. Оба дефекта — из одного корня: денежный код и рабочий код жили в
РАЗНЫХ копиях функции, и регистрация в какой-то момент переключилась с
«копии с деньгами и битым вебхуком» на «копию с рабочим вебхуком без денег».

## Что сделано в этом лупе

Только гигиена долга: в мёртвой копии починены выброшенные результаты и
возврат СТАРОГО БАЛАНСА вместо суммы (при балансе 1000 и цене 500 неудача
давала 1500) — с пометкой, что файл не исполняется.

## Чего это НЕ чинит

Живой путь по-прежнему не списывает. Возврат списания — отдельный луп:
нужно решить, где ему жить (в живой функции или в сцене до события), пройти
по классу «списал — работа не удалась — вернул», написать тесты. Это
изменение поведения на живом денежном пути, его нельзя делать хвостом
чужого PR.

# Приложение: обучение голоса продаёт мёртвую услугу

Тем же лупом: `voiceTrainingWizard` жив и доступен из меню
(`categories.config.ts:219`) и из AI Cover. Он списывал 100⭐, после чего:
таблицы `voice_models` в базе НЕТ (HTTP 404), событие `voice/training.start`
никто не слушает (`voiceTrainingRVC` не зарегистрирована). Измерено:
единственная попытка за всю историю — 2025-12-16, 100⭐, возвращены той же
веткой «upload error».

Сделано по образцу PR #510 («отправитель отказывает честно»): сцена
отказывает на входе, не взяв денег — флаг `VOICE_TRAINING_DISCONNECTED`,
охраняется тестом. Включение обратно — решение владельца: нужны таблица
`voice_models` (схема) и регистрация `voiceTrainingRVC` (меняет статусы).
