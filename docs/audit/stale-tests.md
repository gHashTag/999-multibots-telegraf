# Шесть давних падений: тесты описывали архитектуру, которой нет

`src/__tests__/core/openai/requests.test.ts` месяцами был красным наполовину:
шесть проверок из двенадцати падали. Файл при этом сторожит код генерации
изображений — тот самый, который я правил два дня назад.

Наполовину красный тест не защищает ничего: его падения перестают быть
сигналом.

## Три причины на шесть падений

**Две — устаревшая форма ответа.** Проверки ждали
`{ type, imageUrl }`, а функция давно возвращает ещё и `cost`. Стоимость
появилась вместе с учётом генераций.

**Одна — устаревшие параметры.** Ждали `aspectRatio: '1:1'`, код передаёт
`'9:16'` (вертикаль для Telegram) и добавляет `telegramId`.

**Три — устаревшая архитектура.** Проверки описывали путь через OpenRouter:
подставляли `OPENROUTER_API_KEY`, ждали запрос на
`openrouter.ai/api/v1/chat/completions` и ошибку
`OpenRouter API error: 401`.

Код давно ходит иначе: основной путь — xAI Grok (`GROK_API_KEY`), затем GLM,
затем DeepSeek, затем OpenAI. Ошибка на выходе одна на всех:
`All AI providers failed (Grok, GLM-4.7, DeepSeek, OpenAI)`.

## Что сделано

Ни одна проверка не удалена — пропала бы причина, ради которой её писали.
Все шесть переписаны под то, что код делает на самом деле, и каждая объясняет
в комментарии, чем прежнее ожидание было неверно.

Блок переименован честно: «2. Обычные текстовые запросы **через OpenRouter**» →
«2. Обычные текстовые запросы: **цепочка поставщиков**».

Главные свойства сохранены, а не подогнаны:

- пустой ответ поставщика **не выдаётся человеку за ответ** — раньше это
  проверялось через `Empty response from OpenRouter`, теперь через переход к
  следующему поставщику и общую ошибку;
- при отказе всех поставщиков ошибка **называет их поимённо** — по ней видно,
  что искать.

## Проверено

- 12 из 12 зелёные, три прогона подряд — не флак;
- мутация: подмена адреса Grok на неверный роняет ровно одну проверку;
- `npm run test:gate` показал один «регресс» — это переименованный блок.
  Сверил, что замена на месте и покрывает то же, и обновил снимок. Зелёных
  стало больше на семь.

## Чего это НЕ значит

Тесты теперь описывают текущее поведение — но они его не одобряют. Цепочка из
четырёх поставщиков с общей ошибкой в конце удобна коду и неудобна человеку: он
видит «All AI providers failed», не понимая, что делать. Это отдельный вопрос,
и он не в тестах.
