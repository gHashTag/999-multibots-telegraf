# Что человек видит, когда что-то пошло не так

Прошлые итерации нашли, что бот сообщает НЕ ТО: «средства возвращены», когда
возврат не проходил; «у вас нет моделей», когда обучение висит тринадцать
месяцев. Здесь — соседний класс: бот не сообщает НИЧЕГО, и его родственник:
бот называет выдуманное число.

Замер: `scripts/probe-silent-failure.cjs` (с самопроверкой).

## Знаменатели

Блоки `catch` в сценах, обработчиках, навигации и командах — то есть рядом с
человеком:

| | |
|---|---:|
| всего | 479 |
| отвечают человеку | 247 |
| пробрасывают выше (ответит тот, кто поймает) | 36 |
| без записи в журнал вовсе | 27 |
| **молчат: журнал есть, ответа нет** | **169** |

Молчат чаще всего: `aiPhotoshopScene` (56), `fluxKontextScene` (15),
`morphingWizard` (15).

Оговорка, без которой число врёт: большинство из 169 — вспомогательные функции
(разбор даты, получение аватара группы), где молчать правильно: отвечает
вызывающий. Полный разбор всех 169 — работа не на одну итерацию.

## Найдено по дороге и починено: выдуманная цена

Два места подставляли число, когда настоящую цену узнать не удавалось.

**`handleImageToVideoDirect.ts`**

```ts
} catch (error) {
  logger.error('Price calculation failed', …)
  return 40 // Fallback price
}
```

Расчёт цены упал — с человека списывают сорок звёзд. Услуга может стоить и
пять, и двести. В сообщении «💰 Стоимость: 40 ⭐» стоит то же выдуманное число,
то есть заметить подмену человек не может.

**`core/openai/requests.ts`** — три места с `nanoBananaPrice?.costPerImage || 10`:
списание, отчёт о стоимости и **сумма возврата**. Если запись о модели исчезала
или переименовывалась, все три брали десятку.

## Что сделано

- расчёт цены возвращает `null` вместо выдумки, а обработчик говорит человеку:
  «Не удалось определить стоимость. **Деньги не списаны.** Попробуйте другую
  модель или напишите в поддержку»;
- цена Nano Banana вынесена в одну функцию, возвращающую настоящее число или
  `null`; при `null` списания не происходит, а возврат не делается с громкой
  записью «не знаем сумму» — вернуть не столько хуже, чем не вернуть и сказать
  об этом;
- отчёт о стоимости при неизвестной цене показывает ноль, а не десятку: ноль
  читается как «неизвестно», десятка — как настоящее списание.

Закрыто тестом `src/__tests__/money/no-invented-price.test.ts`. Проверено
мутацией: возврат `return 40` и подстановка `= 10` роняют.

## Две ошибки в собственном инструменте

**Самопроверка спасла сразу.** Первая версия искалки искала `catch` только в
начале строки и не находила `try { … } catch (e) {`. Самопроверка не прошла, и
искалка сама сказала, что ей верить нельзя.

**Ложное завышение.** Первая рабочая версия дала 179 молчащих блоков. В списке
обращений к человеку не было `editMessageText` — а именно им отвечает
`handleImageToVideoDirect`. После уточнения 169. Разница невелика, но она бы
попала в отчёт как факт.

И третье, уже привычное: проверка «в файле больше нет `return 40`» падала на
моём же комментарии, который эту строку цитирует. Комментарии надо вырезать —
это четвёртый раз за неделю.

## Что осталось

169 молчащих блоков. Разбирать их надо по одному: в половине случаев молчание
правильно. Первый кандидат — `aiPhotoshopScene` с 56 блоками: это сцена, где
человек ждёт картинку.
