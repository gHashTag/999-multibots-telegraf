## 🔍 Как работает новая логика:

### Для пользователей БЕЗ подписки (STARS):
1. Видят ВСЕ кнопки меню
2. При нажатии на любую платную функцию:
   - Получают сообщение о недоступности
   - Видят список доступных бесплатных функций
   - Получают предложение оформить подписку

### Для пользователей с NEUROPHOTO:
1. Видят ВСЕ кнопки меню
2. Могут использовать функции фото и изображений
3. При попытке использовать видео функции:
   - Получают сообщение о необходимости NEUROVIDEO
   - Видят список доступных и заблокированных функций

### Для пользователей с NEUROVIDEO:
1. Видят ВСЕ кнопки меню
2. Имеют доступ ко ВСЕМ функциям
3. Никаких ограничений
