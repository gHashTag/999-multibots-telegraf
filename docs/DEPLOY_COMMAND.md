# Claude Code Slash Command: `/deploy`

## 🚀 Автоматический деплой в продакшн

Пользовательская slash команда для Claude Code, которая автоматизирует весь процесс развертывания с проверками безопасности.

## ⚡ Быстрый старт

```bash
/deploy
```

Команда автоматически выполнит весь цикл развертывания с подтверждением.

## 🔧 Что происходит при выполнении

### 1. 🔒 Проверки безопасности
- Сканирует измененные файлы на наличие токенов и секретов
- Проверяет Telegram bot tokens (формат: `BOT_TOKEN_X=`)
- Проверяет OpenAI API keys (формат: `sk-...`)
- Проверяет пароли и общие секреты
- Останавливает деплой при обнаружении утечек

### 2. 📋 Git проверки
- Проверяет статус репозитория
- Убеждается что мы на ветке `production`
- Подготавливает файлы к коммиту

### 3. 🏗️ Сборка проекта
- Выполняет `npm run build`
- Проверяет отсутствие ошибок сборки
- Останавливает процесс при ошибках

### 4. 📝 Автоматический коммит
- Создает коммит с timestamp
- Добавляет стандартное сообщение коммита
- Отправляет изменения в `origin/production`

### 5. 🔄 Обновление продакшн сервера
- SSH подключение к серверу `212.86.115.30`
- Обновляет подмодуль `services/bot-farm`
- Выполняет `git reset --hard origin/production`
- Компилирует TypeScript на сервере

### 6. ⚙️ Перезапуск сервисов
- Перезапускает Docker контейнер `app`
- Ждет 10 секунд для инициализации
- Проверяет статус сервиса

### 7. ✅ Проверка развертывания
- Проверяет статус Docker контейнера
- Анализирует логи на наличие ошибок
- Подтверждает успешный запуск ботов

### 8. 📋 Отчет о развертывании
- Генерирует детальный отчет
- Показывает timestamp, commit hash, статус
- Подтверждает успешное завершение

## 🛡️ Безопасность

### Проверяемые паттерны:
```regex
/BOT_TOKEN_\d+=[0-9]+:[A-Za-z0-9_-]{35}/  # Telegram bot tokens
/sk-[a-zA-Z0-9]{48}/                       # OpenAI API keys  
/(?:password|passwd|pwd).*[:=]\s*[^\s\n]+/i # Passwords
/(?:secret|key|token).*[:=]\s*[^\s\n]+/i   # Generic secrets
/[a-f0-9]{40}/                            # 40-char hex strings
/[A-Za-z0-9]{32,}/                        # Long alphanumeric strings
```

### Исключения (разрешенные файлы):
- `.env` - файл окружения
- `.env.example` - пример файла окружения  
- `docs/` - документация
- `README.md` - документация проекта

## 🚨 Обработка ошибок

### Если обнаружены токены:
```bash
❌ Обнаружен потенциальный секрет в файле: src/config/tokens.ts
❌ Паттерн: /BOT_TOKEN_\d+=[0-9]+:[A-Za-z0-9_-]{35}/
❌ Развертывание остановлено из соображений безопасности
```

### Если ошибки сборки:
```bash
❌ Ошибка при сборке проекта:
src/handlers/newFeature.ts(15,3): error TS2322: Type 'string' is not assignable to type 'number'
```

### Если ошибки SSH подключения:
```bash
❌ Не удалось обновить подмодуль
ssh: connect to host 212.86.115.30 port 22: Connection timed out
```

## 💡 Советы по использованию

1. **Регулярные деплои:** Используйте `/deploy` для каждого значимого изменения
2. **Проверка перед деплоем:** Всегда проверяйте что проект собирается локально
3. **Мониторинг логов:** После деплоя следите за логами несколько минут
4. **Экстренные ситуации:** Используйте `scripts/quick-deploy.sh` если Claude Code недоступен

## 📞 Поддержка

При проблемах с командой `/deploy`:

1. Проверьте SSH подключение
2. Убедитесь что ветка `production` актуальна
3. Проверьте права доступа к продакшн серверу
4. Используйте альтернативный `scripts/quick-deploy.sh`
