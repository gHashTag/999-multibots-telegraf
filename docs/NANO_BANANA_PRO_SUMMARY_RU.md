# Nano Banana Pro - Краткая сводка

## Что сделано

Добавлена новая модель генерации изображений **Nano Banana Pro** от Google в платформу 999-multibots.

## Основная информация

- **Модель**: Nano Banana Pro (Nano Banana 2)
- **Провайдер**: Fal.ai (самый дешёвый из доступных)
- **Цена**: $0.0398 за изображение (25 изображений за $1)
- **Преимущества**:
  - Отличный фотореализм
  - Превосходная отрисовка текста (лучше всех конкурентов)
  - Поддержка разрешений до 4K
  - 10 различных соотношений сторон
  - Естественная эстетика

## Где доступна

1. **Визард Text-to-Image** - пользователи могут выбрать "Nano Banana Pro" из списка моделей
2. **Визард NeuroPhoto** - можно использовать для генерации нейрофото
3. **API** - доступна через UniversalProviderManager

## Технические детали

### Поддерживаемые параметры

**Соотношения сторон:**
- 21:9, 16:9, 3:2, 4:3, 5:4, 1:1, 4:5, 3:4, 2:3, 9:16

**Разрешения:**
- 1K (стандарт), 2K (высокое), 4K (ультра)

**Форматы:**
- JPEG, PNG (по умолчанию), WebP

### Производительность
- Время генерации: 5-10 секунд
- Обработка через очередь Fal.ai
- Автоматические повторы при ошибках

## Как использовать

### Для пользователей
1. Открыть визард "🎨 Текст в изображение"
2. Выбрать модель "Nano Banana Pro"
3. Ввести промпт
4. Получить изображение

### Для разработчиков

```typescript
import { generateNanoBananaPro } from '@/services/generateNanoBananaPro'

const result = await generateNanoBananaPro({
  prompt: 'Красивый закат над горами',
  numImages: 1,
  aspectRatio: '16:9',
  resolution: '2K',
  telegramId: '123456789',
})
```
