# Агент Trinity S³AI — ядро проекта

Агент — это не чат-помощник, который советует. Это исполнитель: у него есть
инструменты, которые **читают и меняют состояние приложения по-настоящему** —
лента, файлы пользователя, шаблоны, публикация. Любой внешний агент может
подключиться к нему по MCP и делать то же самое от имени человека.

---

## Где это в приложении

**Вкладка «Агент»** — вторая в нижней панели мини-аппа. Открываешь, пишешь
задачу словами. Агент сам решает, какие инструменты вызвать, и показывает
работу потоком:

- **▸ размышление** — сворачиваемый блок, видно, ПОЧЕМУ агент выбрал именно
  этот инструмент;
- **чипы инструментов** (`⚙ feed_stats · 53мс`) — доказательство, что агент
  реально смотрел в приложение, а не выдумал ответ;
- **текст** — посимвольно, по мере генерации.

Живой пример: на вопрос «сколько роликов в ленте и кто автор» агент вызвал
`feed_stats`, увидел, что имён там нет, сам дозапросил `feed_list` и ответил
«3 ролика, автор @t27_dev» — числами из инструментов, а не примерными.

## Как подключить СВОЕГО агента по MCP

Идея white-label: подключить можно любого агента — своего Claude, свой скрипт,
любой MCP-клиент. Сервис спроектирован так, чтобы агенту было удобно.

### Шаг 1. Посмотреть карточку подключения (без ключа)

```bash
curl -s https://vibee-render-production.up.railway.app/mcp
```

Отдаёт список инструментов, модель, и честно — чего сервис НЕ умеет.
Агент, получивший голый адрес, первым делом делает GET; поэтому GET отвечает
инструкцией, а не «405».

### Шаг 2. Получить ключ у владельца

Ключ выдаётся на твой `telegram_id` и кладётся в переменную `AGENT_KEYS`
сервиса. Ключ привязан к человеку: инструменты работают от его имени, чужой
`telegram_id` подставить нельзя.

### Шаг 3. Список инструментов

```bash
curl -s https://vibee-render-production.up.railway.app/mcp \
  -H 'X-Agent-Key: ТВОЙ_КЛЮЧ' -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

### Шаг 4. Вызвать инструмент

```bash
curl -s https://vibee-render-production.up.railway.app/mcp \
  -H 'X-Agent-Key: ТВОЙ_КЛЮЧ' -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"feed_stats","arguments":{}}}'
```

### Или поговорить с агентом целиком (модель + инструменты)

```bash
curl -sN https://vibee-render-production.up.railway.app/api/agent/chat \
  -H 'X-Agent-Key: ТВОЙ_КЛЮЧ' -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"Что уже есть в ленте?"}]}'
```

Ответ — потоком NDJSON: строки `{"тип":"размышление"|"текст"|"инструмент"|"результат"|"готово"}`.

## Инструменты

| Инструмент       | Что делает                                                   | Меняет данные |
| ---------------- | ------------------------------------------------------------ | ------------- |
| `whoami`         | кто вызывает: telegram_id, имя, число публикаций             | нет           |
| `feed_stats`     | сводка ленты: авторов, роликов, просмотров, лайков           | нет           |
| `feed_list`      | последние ролики ленты (можно только свои)                   | нет           |
| `feed_get`       | одна запись ЦЕЛИКОМ со слоями (assets, tracks) — для ремикса | нет           |
| `my_assets`      | файлы человека: картинки, видео, озвучка                     | нет           |
| `templates_list` | шаблоны из бандла рендера (не рукописный список)             | нет           |
| `feed_publish`   | опубликовать рилс; текст поста с хештегами обязателен        | **да**        |

Начинать стоит с `whoami` и `feed_stats` — они бесплатны, мгновенны и ничего
не меняют.

Платных генераций (изображение, видео, озвучка, липсинк) у агента пока НЕТ:
списание баланса в сервисе не реализовано, и открывать бесплатный доступ к
платным провайдерам за счёт владельца нельзя. Появится списание — появятся
инструменты.

## Исходный код

| Файл                                                                | Что там                                                                   |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [tools.ts](../../apps/vibee-editor/render/src/agent/tools.ts)       | ЕДИНЫЙ реестр инструментов — один список для чата и MCP                   |
| [chat.ts](../../apps/vibee-editor/render/src/agent/chat.ts)         | петля агента: модель → инструменты → ответ, поток событий                 |
| [provider.ts](../../apps/vibee-editor/render/src/agent/provider.ts) | выбор модели: z.ai (glm-5.3, кодерский эндпоинт) и OpenAI, диагноз отказа |
| [routes.ts](../../apps/vibee-editor/render/src/agent/routes.ts)     | входы: `GET/POST /mcp`, `POST /api/agent/chat`, карточка подключения      |
| [Chat.tsx](../../apps/vibee-editor/player/src/pages/Chat.tsx)       | вкладка «Агент» в мини-аппе: стриминг, размышление, чипы инструментов     |

Один реестр — три входа (чат мини-аппа, внешний MCP, отладка curl). Рукописный
список возможностей в этом проекте уже расходился с реализацией
(`/compositions` обещал шесть шаблонов при одной существующей композиции) —
здесь списка два быть не может.

npm run dashboard
