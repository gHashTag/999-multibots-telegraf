# 📊 Детальная финансовая модель AI Reels (Template 2)

## 🎯 Основная концепция
AI Reels автоматически создает видео с говорящим аватаром на фоне B-roll видео. Стоимость зависит от длины текста, который определяет:
1. Длительность аудио (озвучка)
2. Количество B-roll видео (фоновые клипы по 8 секунд)
3. Длительность lip-sync аватара

## 💰 Структура себестоимости

### 1. 🎬 B-roll видео (Veo 3 Fast через Kie.ai)

**Официальная цена Kie.ai:** $0.40 за 8-секундное видео = **40⭐**

**Как рассчитывается количество B-roll:**
- Длительность аудио ÷ 8 секунд (округление вверх)
- Примеры:
  - 1-8 сек аудио → 1 B-roll (40⭐)
  - 9-16 сек аудио → 2 B-rolls (80⭐)
  - 17-24 сек аудио → 3 B-rolls (120⭐)
  - 25-32 сек аудио → 4 B-rolls (160⭐)

**Почему 40⭐, а не 160⭐:**
- Мы используем Veo 3 **Fast** модель (экономичная версия)
- Официальная цена Kie.ai: $0.40 = 40⭐ за 8 секунд
- Quality версия стоила бы $2.00 = 200⭐ за 8 секунд

### 2. 🎤 Озвучка (ElevenLabs)

**Стоимость:** 0.5⭐ за секунду аудио

**Расчет длительности:**
- Количество символов × 0.06 = секунды аудио
- Средняя скорость речи: ~60 символов в секунду
- Примеры:
  - 150 символов → 9 сек → 4.5⭐
  - 300 символов → 18 сек → 9⭐
  - 500 символов → 30 сек → 15⭐

### 3. 👤 Аватар (Lip-sync)

**Три варианта сервисов:**

| Сервис | Стоимость/сек | Особенности |
|--------|---------------|-------------|
| **🎭 Hedra** | 5⭐/сек | Загрузка своего фото |
| **🎬 HeyGen** | 3⭐/сек (наш ключ)<br>0⭐/сек (ключ клиента) | Готовые проф. аватары |
| **🎯 Fal** | 4⭐/сек (наш ключ)<br>0⭐/сек (ключ клиента) | Высокое качество lip-sync |

### 4. 🔧 Инфраструктура

**Базовая стоимость:** 25⭐
- Railway хостинг
- Inngest обработка
- Selectel S3 хранилище
- Webhook callbacks

**Дополнительно:** 5⭐ за каждый B-roll
- Обработка видео
- Склейка фрагментов
- Рендеринг финального видео

## 📈 Формула расчета

```
Себестоимость = B-rolls + Озвучка + Аватар + Инфраструктура
              = (Кол-во B-roll × 40) + (Сек × 0.5) + (Сек × Avatar_Rate) + (25 + Кол-во B-roll × 5)

Финальная цена = Себестоимость × 1.5 (наценка 50%)
```

## 💡 Примеры расчетов

### Пример 1: Короткое видео (150 символов)
- **Текст:** 150 символов → 9 секунд аудио
- **B-rolls:** 2 клипа (9÷8 округлено вверх) × 40⭐ = **80⭐**
- **Озвучка:** 9 сек × 0.5⭐ = **4.5⭐**
- **Аватар (Hedra):** 9 сек × 5⭐ = **45⭐**
- **Инфраструктура:** 25 + (2×5) = **35⭐**
- **Себестоимость:** 80 + 4.5 + 45 + 35 = **164.5⭐**
- **С наценкой 1.5x:** **247⭐** (~336₽)

### Пример 2: Среднее видео (300 символов)
- **Текст:** 300 символов → 18 секунд аудио
- **B-rolls:** 3 клипа × 40⭐ = **120⭐**
- **Озвучка:** 18 сек × 0.5⭐ = **9⭐**
- **Аватар (Fal):** 18 сек × 4⭐ = **72⭐**
- **Инфраструктура:** 25 + (3×5) = **40⭐**
- **Себестоимость:** 120 + 9 + 72 + 40 = **241⭐**
- **С наценкой 1.5x:** **362⭐** (~492₽)

### Пример 3: Длинное видео (500 символов)
- **Текст:** 500 символов → 30 секунд аудио
- **B-rolls:** 4 клипа × 40⭐ = **160⭐**
- **Озвучка:** 30 сек × 0.5⭐ = **15⭐**
- **Аватар (HeyGen наш):** 30 сек × 3⭐ = **90⭐**
- **Инфраструктура:** 25 + (4×5) = **45⭐**
- **Себестоимость:** 160 + 15 + 90 + 45 = **310⭐**
- **С наценкой 1.5x:** **465⭐** (~632₽)

### Пример 4: С ключом клиента HeyGen (300 символов)
- **B-rolls:** 3 клипа × 40⭐ = **120⭐**
- **Озвучка:** 18 сек × 0.5⭐ = **9⭐**
- **Аватар (HeyGen клиента):** 18 сек × 0⭐ = **0⭐** ✅
- **Инфраструктура:** 25 + (3×5) = **40⭐**
- **Себестоимость:** 120 + 9 + 0 + 40 = **169⭐**
- **С наценкой 1.5x:** **254⭐** (~345₽)
- **Экономия:** 108⭐ по сравнению с нашим ключом

## 🔍 Почему динамическое ценообразование важно?

### Проблема старой модели (фиксированная цена 366⭐):
- **8 сек видео:** Реальная стоимость ~150⭐, цена 366⭐ = переплата 216⭐
- **18 сек видео:** Реальная стоимость ~362⭐, цена 366⭐ = почти без прибыли
- **30 сек видео:** Реальная стоимость ~465⭐, цена 366⭐ = **убыток 99⭐!**

### Преимущества новой модели:
✅ Справедливая цена за короткие видео
✅ Покрытие расходов на длинные видео
✅ Прозрачное ценообразование для клиентов
✅ Стимул использовать свои API ключи для экономии
