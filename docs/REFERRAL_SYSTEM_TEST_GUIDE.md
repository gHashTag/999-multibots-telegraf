# 🔗 Руководство по тестированию реферальной системы

## 📋 Обзор системы

Реферальная система позволяет существующим пользователям приглашать новых через специальные ссылки. При регистрации нового пользователя:
1. Сохраняется информация о том, кто его пригласил
2. Отправляется уведомление пригласившему
3. Отправляется уведомление в админский канал

## 🧪 Подготовка к тестированию

### 1. Убедитесь, что бот запущен в dev режиме:
```bash
cd /Users/playra/999-multibots-telegraf
bun dev
```

### 2. Проверьте существование тестового пользователя:
```bash
bun scripts/check-user-exists.ts
```

### 3. Если пользователь существует, удалите его:
```bash
bun scripts/delete-test-user.ts
```

## 📱 Тестовые сценарии

### Сценарий 1: Регистрация с реферальным кодом

1. **Отправьте боту команду с реферальным кодом:**
   ```
   /start 144022504
   ```

2. **Ожидаемое поведение:**
   - Бот создаст нового пользователя
   - В поле `inviter` будет сохранен UUID пригласившего
   - Пригласивший получит уведомление
   - В админский канал придет сообщение о регистрации

3. **Что проверить в логах:**
   ```
   📝 [START COMMAND] Start parameter detected: 144022504
   🔗 [START COMMAND] Referral code set: 144022504
   🆕 [START COMMAND] User does not exist, entering CreateUserScene
   🔍 [CreateUserScene] Looking up inviter by telegram_id: 144022504
   ✅ [CreateUserScene] Found inviter UUID: <uuid>
   📝 [CreateUserScene] Creating user with data:
   ✉️ [CreateUserScene] Уведомление пригласившему отправлено
   ```

### Сценарий 2: Регистрация с промо-кодом NEUROPHOTO

1. **Отправьте боту команду:**
   ```
   /start neurophoto
   ```

2. **Ожидаемое поведение:**
   - Создается новый пользователь
   - Активируется промо-подписка NEUROPHOTO
   - Начисляются 476 звезд
   - Отправляется уведомление о промо-активации

3. **Что проверить в логах:**
   ```
   🎁 [CreateUserScene] Promo link detected
   📸 НейроФото промо-подписка активирована!
   ```

### Сценарий 3: Регистрация с промо-кодом NEUROVIDEO

1. **Отправьте боту команду:**
   ```
   /start neurovideo
   ```

2. **Ожидаемое поведение:**
   - Создается новый пользователь
   - Активируется промо-подписка NEUROVIDEO
   - Начисляются 1303 звезды
   - Отправляется уведомление о промо-активации

3. **Что проверить в логах:**
   ```
   🎁 [CreateUserScene] Promo link detected
   🎬 НейроВидео промо-подписка активирована!
   ```

### Сценарий 4: Использование реферальной ссылки

1. **Получите свою реферальную ссылку:**
   - Отправьте боту команду `/menu`
   - Нажмите "👥 Пригласить друга"
   - Скопируйте ссылку вида: `https://t.me/ai_koshey_bot?start=YOUR_ID`

2. **Протестируйте с другим аккаунтом:**
   - Откройте ссылку с другого Telegram аккаунта
   - Нажмите "Start" в боте
   - Проверьте, что реферал записался

## 🔍 Проверка результатов в базе данных

После регистрации проверьте в Supabase:

1. **Таблица `users`:**
   - Новый пользователь создан
   - Поле `inviter` содержит UUID пригласившего (если был реферальный код)
   - Поле `telegram_id` соответствует ID пользователя

2. **Таблица `user_subscriptions`:**
   - Если использовался промо-код, должна быть создана подписка
   - Проверьте тип подписки (NEUROPHOTO или NEUROVIDEO)
   - Проверьте баланс звезд

## 🐛 Решение проблем

### Пользователь не создается:
1. Проверьте, что пользователь действительно не существует в БД
2. Убедитесь, что переменные окружения Supabase настроены
3. Проверьте логи на наличие ошибок

### Реферальный код не сохраняется:
1. Убедитесь, что формат команды правильный: `/start 144022504`
2. Проверьте, что пригласивший существует в БД
3. Посмотрите логи для отладки

### Промо-код не активируется:
1. Проверьте, что пользователь новый
2. Убедитесь, что промо еще не был использован
3. Проверьте правильность промо-кода

## 📊 Мониторинг

Для отслеживания работы реферальной системы:

1. **Логи бота:**
   ```bash
   # Следите за логами в реальном времени
   tail -f logs/bot.log | grep -E "START|CreateUser|inviter"
   ```

2. **База данных:**
   - Регулярно проверяйте новых пользователей
   - Отслеживайте связи inviter-invitee
   - Мониторьте использование промо-кодов

## 🔄 Сброс тестового окружения

Для повторного тестирования:

1. Удалите тестового пользователя:
   ```bash
   bun scripts/delete-test-user.ts
   ```

2. Очистите сессию бота (перезапустите):
   ```bash
   # Остановите бота (Ctrl+C)
   # Запустите снова
   bun dev
   ```

3. Повторите тестовый сценарий
