# Исправление доступа к меню для пользователей без подписки

## Проблема
Пользователи без подписки не могли попасть в главное меню бота. При попытке выполнить команду `/menu` они автоматически перенаправлялись в сцену подписки, что создавало замкнутый круг и не позволяло им ознакомиться с функциями бота.

## Решение

### 1. Убрана проверка подписки при входе в меню
**Файл:** `src/scenes/startScene/index.ts`
- Удалена проверка подписки при выполнении команды `/menu`
- Теперь все пользователи могут войти в главное меню

### 2. Добавлены базовые функции для пользователей без подписки
**Файл:** `src/menu/mainMenu.ts`
- Пользователи со статусом STARS (без подписки) теперь видят:
  - 👥 Пригласить друга - для получения бонусов через реферальную систему
  - 💬 Техподдержка - для связи с поддержкой
  - 🌐 Язык - для смены языка интерфейса
  - 💫 Оформить подписку - для покупки подписки

### 3. Убрана проверка подписки для кнопки "Пригласить друга"
**Файл:** `src/hearsHandlers.ts`
- Функция приглашения друзей теперь доступна всем пользователям
- Это позволяет новым пользователям получать бонусы через реферальную систему

## Структура меню

### Для пользователей БЕЗ подписки (STARS):
```
[👥 Пригласить друга] [💬 Техподдержка]
           [🌐 EN/RU]
      [💫 Оформить подписку]
```

### Для пользователей с подпиской NEUROPHOTO:
```
    [🤖 Цифровое тело] [📸 Нейрофото]
  [🔍 Промпт из фото] [⬆️ Увеличить качество]
       [📺 Транскрибация Reels]
    [💰 Баланс] [💎 Пополнить баланс]
  [👥 Пригласить друга] [💬 Техподдержка]
           [🌐 EN/RU]
      [💫 Оформить подписку]
```

### Для пользователей с подпиской NEUROVIDEO:
Все функциональные кнопки + сервисные кнопки

## Тестирование
Создан тестовый скрипт `scripts/test-menu-access.ts` для проверки корректности отображения меню для разных типов подписок.

Запуск теста:
```bash
npx tsx scripts/test-menu-access.ts
```

## Преимущества решения
1. **Улучшенный UX** - новые пользователи могут ознакомиться с ботом
2. **Доступность** - базовые функции (поддержка, реферальная система) доступны всем
3. **Прозрачность** - пользователи видят, какие функции доступны с подпиской
4. **Мотивация** - видя заблокированные функции, пользователи мотивированы оформить подписку

## Защита платных функций
Все платные функции по-прежнему защищены проверкой подписки через `checkSubscriptionGuard`:
- При попытке использовать платную функцию без подписки пользователь перенаправляется в сцену оформления подписки
- Защита реализована на уровне обработчиков команд в `hearsHandlers.ts`

## Изменённые файлы
1. `src/scenes/startScene/index.ts` - убрана проверка подписки для /menu
2. `src/menu/mainMenu.ts` - добавлены базовые кнопки для пользователей без подписки
3. `src/hearsHandlers.ts` - убрана проверка подписки для "Пригласить друга"
4. `scripts/test-menu-access.ts` - добавлен тест для проверки функциональности
5. `docs/MENU_ACCESS_FIX.md` - документация изменений
