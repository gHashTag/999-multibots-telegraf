## 💡 Логика ценообразования

### Для конкурентных видео моделей (Sora, Veo):

```typescript
// БЕЗ наценки - конкурентные цены
if (modelId === 'sora-2' || modelId === 'sora-2-pro' || ...) {
  return Math.floor(totalCostUSD / STAR_COST_USD)
}
```

**Расчет**: Цена = (Kie.ai USD цена) / $0.016

### Для остальных моделей:

```typescript
// С наценкой 50%
return usdToStars(totalCostUSD)

function usdToStars(baseCostUSD) {
  const starsBeforeMarkup = baseCostUSD / STAR_COST_USD
  const starsWithMarkup = starsBeforeMarkup * MARKUP_MULTIPLIER
  return Math.floor(starsWithMarkup)
}
```

**Расчет**: Цена = (USD / $0.016) × 1.5
