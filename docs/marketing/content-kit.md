# Контент-кит Trinity S³AI: рилсы, карусели, сторис

Готовые концепты для раскрутки приложения и агента. Голос — SOUL.md:
измерение вместо прилагательного, границы честно. Каждый концепт уже
написан как сценарий, а не как тема «надо бы снять». Числа в квадратных
скобках `[подставить]` заполняются в момент съёмки реальными значениями
из интерфейса — врать нельзя, видно будет.

Удивлять здесь предлагается не «ИИ может всё», а обратным: агент ПОКАЗЫВАЕТ
работу — размышление, чипы инструментов с миллисекундами, честные «этого
я не умею». Рынок наводнён обещаниями; публичная граница — это и есть крючок.

---

## Рилсы (9:16, 15–45 с)

### R1. «Советчики советуют. Агент делает.» — флагман

- **Крючок (0–3с):** чёрный кадр, зелёная строка: «Сколько ИИ-советчиков
  нужно, чтобы описать твою ленту? Ноль. Нужен один агент.»
- **Демонстрация:** скрин вкладки «Агент»: вопрос «что уже есть в ленте?»,
  стрим размышления, чипы `⚙ feed_list · [N]мс`, `⚙ feed_stats · [N]мс`.
- **Число:** «[N] вызовов инструментов, [N] мс, ни одного выдуманного
  названия — все три ролика взяты из базы, id видны.»
- **Граница:** «Платной генерации у агента нет: списание баланса не
  реализовано. Stated rather than smoothed.»
- **Финал:** тождество φ² + 1/φ² = 3 + «Попробуй — вкладка Агент».

### R2. «Живой диалог двух агентов»

Два окна рядом: Claude (внешний) пишет агенту Trinity по MCP-коннектору,
Trinity отвечает, вызывая инструменты. Титры — кто кого вызвал.

- Число: «[N] витков петли, лимит 8 — видно на экране».
- Граница: «Оба агента честно говорят, чего не могут».

### R3. «Копируешь одну строку — твой Claude уже в приложении»

Экран: кнопка «Copy to agent» на лендинге → вставка в Claude Code →
`tools/list` → ответ. Без монтажных склеек в момент истины.

- Финал: «Один URL. Один заголовок. Ноль настроек. measured.»

### R4. «Ретракция как контент»

«Мы обещали агенту публикацию с хештегами. Он отклонил мой текст без
хештегов. Публикую скрин отказа — это канон, а не баг.» Скрин ошибки
инструмента feed_publish + успешная публикация после правки.

### R5. «Что агент НЕ сделает за тебя» — анти-маркетинг

Список на чёрном: не сгенерирует видео (нет списания), не выдумает id,
не опубликует без текста. Каждый пункт — скрин REAL отказа.

- Финал: «Границы продают лучше обещаний. 16 ретракций на t27.ai —
  тому свидетель.»

### R6. «53 миллисекунды правды»

Макро-скрин чипа инструмента `⚙ feed_stats · 53мс`. Голос за кадром:
«Вот сколько стоит правда об одном вопросе. Прилагательные дороже.»

### R7. «Ремикс по id»

Агенту дают id ролика из ленты: `feed_get` → слои, треки, ассеты.
«Открыл целиком, со слоями. Ремикс — это теперь запрос, а не вечер.»

- Граница: «Рендер ремикса — в редакторе, не в чате. Пока. plan, not result.»

### R8. «Один день с агентом» — таймлапс

Утро: вопрос про ленту. День: три совета от агента по своим же цифрам.
Вечер: публикация через агента. Счётчик вызовов инструментов растёт.

### R9. «MCP-карточка за один curl»

Терминал: `curl -s https://vibee-render-production.up.railway.app/mcp`
— карточка инструментов. «Это весь онбординг. Дальше — твой ключ.»

### R10. «Нуар-серия: Золотая Литейная»

Визуал из айдентики `club-reel-noir`: ч/б, единственное золотое пятно —
заголовок. Текст телеграфным стилем: «Лента. Три ролика. Ноль лайков.
Агент видит это первым. И говорит вслух.»

## Карусели (1080×1350, 6–8 слайдов)

### K1. «Агент против чат-бота» — сравнение без эпитетов

1. «Чат-бот советует. Агент делает.» 2. Скрин: агент читает ленту
   (инструмент). 3. Скрин: чат-бот «представляю, что у тебя…». 4. Таблица:
   у кого данные настоящие. 5. Чего нет у агента (генерации). 6–7. Как
   подключить своего (MCP, 3 шага). 8. Тождество + ссылка.

### K2. «7 инструментов, 0 магии»

По слайду на инструмент: имя, что реально делает, что возвращает,
сколько мс на продовом замере. Финал: «Это всё. Ничего скрытого.»

### K3. «Почему агент отказался публиковать» — канон хештегов

Слайд-отказ → слайд-правило → слайд-успех. Мораль: «Правила, которые
исполняет машина, честнее правил, которые пишет маркетинг.»

### K4. «Ternary mind: от φ к рилсам» — мост бренда

1. φ² + 1/φ² = 3. 2. GFTernary — вес, TNF — аккумулятор. 3. 52 теоремы,
   16 ретракций. 4. «Тот же инженер сделал агента для контента». 5–7.
   Агент в работе. 8. t27.ai + приложение.

### K5. «Личный кабинет = вкладка Агент»

Пошагово: открыть мини-апп → вкладка Агент → спросить → увидеть работу →
подключить своего по MCP. Скрины реальные, стрелки зелёные #00FF88.

## Сторис-сетки (1080×1920, 3–5 шт.)

### S1. «Спроси агента» (интерактив)

1. «Задай агенту вопрос — я передам. Пиши в ответ.» 2. Скрин ответа
   (размышление + чипы). 3. Опрос: «поверил / проверит сам».

### S2. «Предскажи число» (пререгистрация)

1. «Сколько мс займёт у агента сводка ленты? Пиши вариант.» 2. Скрин
   чипа с реальным числом. 3. «Сказало [N] человек. Правы — [N].»
2. «Предсказание напечатано до измерения. Так работает t27.ai.»

### S3. «Copy to agent» — сетка подключения

1. Кнопка на лендинге. 2. Вставка в Claude Code. 3. Первый ответ
   агента. 4. «Твой агент уже умеет всё это» — список инструментов.

### S4. «Граница дня»

Один скрин честного отказа агента + подпись: «Сегодня агент не умеет Х.
Завтра — план. measured → plan → measured.»

## Правила публикации

- В текст поста — число из интерфейса, тег статуса, один хештег-якорь
  (#TrinityS3AI, #агентныйрилс, #t27ai — не больше трёх).
- Сначала граница, потом хвастовство — если хвастаться нечем, одна
  граница тоже пост.
- Скрины без ретуши: чипы миллисекунд видны, ошибки не замазаны.
- Каждую неделю — одна ретракция или одно «не вышло»: серия «Граница дня».
