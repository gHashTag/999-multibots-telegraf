## 💡 Инструкции для тестирования

### 1. Перед тестированием
Убедитесь, что в продакшн `.env` есть:
```bash
KIE_AI_API_KEY=ваш_реальный_kie_ai_ключ
```

### 2. Тестовые сценарии
1. **Текст в видео:**
   - Выберите "Создать видео из текста"
   - В списке моделей должны появиться модели Kie.ai с правильными ценами
   - Выберите `Kie.ai Veo 3 Fast (23 ⭐)`
   - Должна появиться опция выбора длительности (2-10 сек)

2. **Изображение в видео:**
   - Выберите "Создать видео из изображения"
   - Должны быть доступны `Kie.ai Veo 3 Fast` и `Kie.ai Runway Aleph`

3. **Проверка цен:**
   - Цены должны соответствовать таблице выше
   - При изменении длительности цена должна пересчитываться
