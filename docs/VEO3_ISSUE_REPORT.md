# Отчет о проблеме с генерацией видео Veo 3

## Проблема
При попытке генерации видео через модель Veo 3 Fast пользователь получает ошибку:
```
❌ Произошла ошибка.
Ошибка: Invalid videoUrl:
```

## Анализ

### 1. Клиентская часть (Telegram Bot)
✅ **Работает корректно**
- Правильно отправляет запрос на сервер с параметрами:
  - prompt: "shaman"
  - videoModel: "veo-3-fast"
  - aspectRatio: "9:16"
  - duration: 8
- Получает jobId от сервера
- Корректно проверяет статус генерации

### 2. Серверная часть (AI Server)
❌ **Проблема на сервере**

Сервер возвращает статус `failed` с ошибкой:
```json
{
  "status": "failed",
  "error_message": "Invalid videoUrl: "
}
```

## Корневая причина
Проблема возникает на сервере при обработке ответа от Replicate API. Сервер не может извлечь `videoUrl` из ответа Replicate.

## Что уже сделано на стороне клиента

### 1. Добавлено детальное логирование
- В `handleVideoReady` - проверка на undefined/пустой URL
- В `monitorVideoGeneration` - логирование ответов сервера
- В `checkVideoGenerationStatus` - полное логирование ответов
- В `generateTextToVideo` - логирование запросов и ответов

### 2. Улучшена обработка ошибок
- Проверка на undefined videoUrl перед отправкой видео
- Показ понятного сообщения пользователю при ошибке

### 3. Создан тестовый скрипт
`tests/test-veo3-generation.ts` - для отладки генерации видео

## Необходимые действия на сервере

### 1. Проверить интеграцию с Replicate API
- Убедиться что используется правильная модель для Veo 3
- Проверить формат ответа от Replicate
- Добавить логирование полного ответа от Replicate

### 2. Исправить извлечение videoUrl
Вероятно, проблема в коде типа:
```javascript
// Неправильно
const videoUrl = replicateResult.videoUrl

// Правильно (например)
const videoUrl = replicateResult[0] || replicateResult.output || replicateResult.url
```

### 3. Добавить fallback для разных форматов ответа
Разные модели Replicate могут возвращать результат в разных форматах.

## Временное решение
В коде добавлен mock ответ при недоступности сервера:
```javascript
if (error.code === 'ECONNREFUSED') {
  return {
    success: true,
    videoUrl: 'https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4'
  }
}
```

## Логи для отладки
При следующей попытке генерации будут собраны детальные логи:
1. Полный запрос к серверу
2. Полный ответ от сервера
3. Статус job'а на каждом этапе
4. Точная ошибка при обработке videoUrl

## Контакт
Для исправления проблемы на сервере необходимо:
1. Проверить логи сервера при генерации видео
2. Исправить обработку ответа от Replicate API
3. Протестировать с реальной моделью Veo 3
