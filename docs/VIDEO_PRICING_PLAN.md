# 📊 План тестирования цен видео генерации

## 🎯 Цель тестирования
Убедиться, что все видео модели имеют корректные цены с учетом:
- Актуальных цен провайдеров (2025)
- Правильной наценки (50% = коэффициент 1.5)
- Конвертации USD → Stars (1 star = $0.016)

## 📈 Формула расчета цены

```
Финальная цена в звездах = (Базовая цена в USD × Длительность) / 0.016 × 1.5
```

Где:
- **Базовая цена в USD** - цена за секунду от провайдера
- **Длительность** - стандартная длительность видео (обычно 5-8 сек)
- **0.016** - стоимость одной звезды в USD
- **1.5** - коэффициент наценки (50% прибыль)

### Шаг 2: Расчет финальных цен

#### Пример расчета для Kling v1.6 Pro:
```
Базовая цена: $0.098/сек
Длительность: 6 сек
Стоимость: $0.098 × 6 = $0.588
Цена в звездах без наценки: $0.588 / $0.016 = 36.75 звезд
С наценкой 50%: 36.75 × 1.5 = 55.125 ≈ 55 звезд
```

## 🚨 Известные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Списывается 236⭐ | Неправильный расчет basePrice × duration | Фиксированные цены в calculateFinalPrice |
| Множественные видео | Нет блокировки дублей | videoTaskCache с TTL 15 мин |
| Network errors | Нет retry механизма | downloadFileHelper с 3 попытками |
| Сплюснутые видео | Неправильный aspect ratio | Автоматический выбор 9:16 для вертикальных |
