# 🛡️ Husky Security Guide - Защита от Утечки Токенов

## 🎯 Цель

Настроить Husky как мощную систему защиты от утечки токенов, секретов и других чувствительных данных в Git репозитории.

## 🔧 Установленные Защиты

### 1. **Pre-commit Hook** (`.husky/pre-commit`)
- ✅ Проверка на утечку токенов перед каждым коммитом
- ✅ Автоматический запуск линтера и форматирования
- ✅ Блокировка коммита при обнаружении токенов

### 2. **Pre-push Hook** (`.husky/pre-push`)
- ✅ Дополнительная проверка безопасности перед push
- ✅ Защита веток `main` и `production` от прямого push
- ✅ Требование Pull Request для защищенных веток

### 3. **Prepare-commit-msg Hook** (`.husky/prepare-commit-msg`)
- ✅ Проверка сообщений коммитов на наличие секретов
- ✅ Блокировка URL с токенами в сообщениях
- ✅ Предупреждения о потенциальных секретах

### 4. **Lint-staged Configuration** (`.lintstagedrc.json`)
- ✅ Автоматическая проверка безопасности для всех файлов
- ✅ Проверка TypeScript, JavaScript, JSON и Markdown файлов
- ✅ Интеграция с ESLint и Prettier

## 🚀 Использование

### Автоматические Проверки

```bash
# При каждом коммите автоматически запускается:
git commit -m "feat: add new feature"
# ✅ Проверка токенов
# ✅ Линтинг и форматирование
# ✅ Проверка сообщения коммита
```

### Ручные Проверки

```bash
# Проверка текущих изменений
npm run security:scan

# Сканирование истории Git
npm run security:history

# Полная проверка безопасности
npm run security:full
```

## 🔍 Что Проверяется

### Критические Токены
- **Telegram Bot Tokens**: `123456789:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`
- **OpenAI API Keys**: `sk-1234567890abcdef1234567890abcdef1234567890abcdef`
- **GitHub Personal Access Tokens**: `ghp_1234567890abcdef1234567890abcdef123456`
- **JWT Tokens**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`
- **Приватные ключи**: `-----BEGIN PRIVATE KEY-----`

### Подозрительные Паттерны
- **Хардкод токенов**: `BOT_TOKEN = "actual_token_here"`
- **Хардкод секретов**: `SECRET_KEY = "secret_value"`
- **Хардкод паролей**: `password = "actual_password"`
- **Webhook секреты**: `webhook_secret = "secret_value"`
- **SSH ключи**: `ssh-rsa AAAAB3NzaC1yc2E...`

### Сообщения Коммитов
- Слова: `token`, `secret`, `password`, `key`, `api_key`, `auth_token`
- URL с токенами: `https://example.com?token=abc123`

## 🚫 Что Блокируется

### Автоматическая Блокировка
- ❌ Коммиты с токенами в коде
- ❌ Push в защищенные ветки (`main`, `production`)
- ❌ Сообщения коммитов с URL токенами
- ❌ Файлы с хардкод секретов

### Принудительное Пропуск
```bash
# НЕ РЕКОМЕНДУЕТСЯ!
git commit --no-verify
git push --no-verify
```

## 🛠️ Настройка

### Установка Husky
```bash
# Установка зависимостей
npm install --save-dev husky lint-staged

# Инициализация Husky
npx husky install

# Добавление хуков
npx husky add .husky/pre-commit "npm run lint-staged"
npx husky add .husky/pre-push "npm run security:scan"
```

### Конфигурация Lint-staged
```json
{
  "*.ts": [
    "eslint --fix",
    "bash -c './scripts/security-token-guard.sh'"
  ],
  "*.js": [
    "eslint --fix", 
    "bash -c './scripts/security-token-guard.sh'"
  ]
}
```

## 🔧 Скрипты Безопасности

### `scripts/security-token-guard.sh`
- Проверка staged файлов на токены
- 11 различных паттернов токенов
- Цветной вывод результатов
- Подробные рекомендации

### `scripts/git-history-security-scan.sh`
- Сканирование истории Git
- Проверка последних 50 коммитов
- Поиск токенов в изменениях
- Рекомендации по очистке

## 🚨 Экстренные Ситуации

### Если Токен Уже Попал в Git
```bash
# 1. Немедленно отозвать токен
# 2. Создать новый токен
# 3. Обновить .env файлы
# 4. Очистить историю Git

# Очистка истории (ОСТОРОЖНО!)
git rebase -i HEAD~N  # Удалить коммит с токеном
git push --force-with-lease
```

### Если Нужно Временно Отключить Проверки
```bash
# ВРЕМЕННО (только для экстренных случаев!)
git commit --no-verify
git push --no-verify
```

## 📋 Чек-лист Безопасности

### Перед Коммитом
- [ ] Проверен код на токены: `npm run security:scan`
- [ ] Используются переменные окружения
- [ ] .env файлы в .gitignore
- [ ] Нет хардкода секретов

### Перед Push
- [ ] Пройдены все проверки безопасности
- [ ] Создан Pull Request для защищенных веток
- [ ] Проверена история на токены: `npm run security:history`

### Регулярно
- [ ] Сканирование истории: `npm run security:history`

- [ ] Проверка .gitignore
