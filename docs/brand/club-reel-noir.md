# NoirReel — канон рилсов клуба «Золотая Литейная»

Третий фирменный контур, задан владельцем 2026-08-22. Не путать с двумя
другими: промо (SplitTalkingHead: неон, жёлтый Montserrat, сплит) и блог
(TrinityBlogReel: барочная антиква, крем и золото обложек #C9A24B).

## Футаж: чёрно-белый нуар с эталонного фото

Эталон — ч/б фото владельца: смокинг-тройка, бабочка, белая рубашка,
белый платок, КЛАССИЧЕСКИЕ ЧЁРНЫЕ ВАЙФАРЕРЫ (не белые футуристические),
жёсткий боковой свет, глубокий чёрный фон. **Единственный цвет в кадре —
золотой треугольный значок на левом лацкане.**

Правила футажа:

1. Строгий монохром. Никакого неона, жёлтых худи, цепей, наушников.
2. Планы липсинка меняются на монтажных стыках; все дорожки — img2img
   с эталона (flux-kontext-pro) + omni-human на ОДНО аудио, поэтому
   склейка в любой точке не сбивает синхрон губ.
3. Рилс открывается КРУПНЫМ лицом («начинать надо с крупного лица»).
4. Резы — по границам фраз (из word-таймингов whisperx), не по метроному.

Канонические планы в storage `images/relaunch/`: `noir-close.jpg` (крупный),
`noir-tux2.jpg` (средний, как эталон), `noir-desk.jpg` (за столом с FPGA),
`noir-wide.jpg` (в коридоре стоек). Липсинки — `noir-lip-*.mp4`.

## Графика: дизайн-система главной t27.ai

Токены из `apps/website/src/index.css` — менять только синхронно с сайтом:

| Токен | Значение | Где в рилсе |
|---|---|---|
| фон | `#000000` | финальная карточка |
| текст | `#FFFFFF` | титры, словомарка TRINITY |
| приглушённый | `#888888` | eyebrow, подписи |
| акцент | `#00FF88` | точка в шапке, черта над eyebrow — и всё |
| золото | `#FFD700` | ТОЛЬКО имя клуба и слово-адрес CTA |
| шрифт | Outfit (+ Jost для кириллицы) | всё |

Титры: по одному слову, Outfit 800, 92px, капс, белые; слово-адрес
(`t27…/…`) — золотом и мельче (76px). Никакого жёлтого #FFFF00.

Финальная карточка = герой главной: зелёная черта 64×3 → eyebrow
приглушённым капсом → имя клуба золотом → белая кнопка-пилюля с чёрным
текстом `t27.ai/foundry` → подпись «оплата в боте · @t27ai_bot».

## Звук

- Голос — клон владельца, MiniMax `speech-02-hd`, `voice_id R8_5GW2UI4A`.
- Музыка — Chill Memphis Phonk, вариант 1 (`phonk1.mp3`), громкость 0.07.
  Владелец явно вернул фонк в этот контур («где фонк?»), поэтому прежнее
  правило «фонк только в промо» здесь не действует.
- Тайминги титров — whisperx `align_output: true`, не на глаз.

## Как собрать рилс

```bash
cd apps/vibee-editor/render
# 1. дорожка: планы режутся по границам фраз, всё в 1080×1920
ffmpeg -i noir-lip-close.mp4 -i noir-lip-tux2.mp4 ... -filter_complex "...concat..." lip-noir.mp4
# 2. рендер
npx remotion render src/index.noir.ts NoirReel out/club-noir.mp4 --props=/tmp/noir-props.json
```

Пропсы: `lipSyncVideo`, `captions` (whisperx), `music`, `brand{...}`,
опционально `cutaways`. Длительность считается из дорожки (calculateMetadata),
карточка стартует после последнего слова.

## Каноничное имя компании

**Trinity S³AI** — на обоих языках, не переводится и не сокращается. В ASCII-
контекстах (LaTeX, arXiv, имена файлов) допустимо `Trinity S3AI`.

компании оказывалось два имени, и материалы переставали читаться как одно
издание.

## Правила выпуска рилса

Три вещи обязательны к каждому ролику, независимо от канона.

1. **Новые сцены под каждый рилс.** Эталон лица один и тот же
   (`relaunch/scene-tux.jpg`), но планы генерируются ЗАНОВО через img2img
   под конкретный сценарий. Повтор одних и тех же четырёх кадров из ролика
   в ролик читается как шаблон, а не как съёмка.
   Модели: `black-forest-labs/flux-kontext-pro` — планы с сохранением
   личности; `openai/gpt-image-1` (доступна через Replicate) — гравюрные
   врезки в стиле блога, они идут в `cutaways`.

2. **Текст для Instagram с хештегами — вместе с видео, всегда.** Ролик без
   подписи опубликовать нельзя, поэтому отдавать его отдельно означает
   отдавать половину работы. Формат: русская и английская версии, сильный
   первый экран до 125 знаков, явный CTA, вопрос для комментариев, пять
   тегов (1 брендовый + 3 нишевых + 1 широкий) и текст на обложку.

3. **Числа сверяются перед записью, а не берутся из памяти.** Счётчики
   вроде числа принятых патчей меняются: перед озвучкой они опрашиваются
   заново, иначе ролик расходится с реальностью в день выхода.
