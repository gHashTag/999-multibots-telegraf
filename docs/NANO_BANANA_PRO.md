# Интеграция Nano Banana Pro

## Обзор

Nano Banana Pro (также известная как Nano Banana 2) — это передовая модель генерации изображений от Google, теперь интегрированная в платформу 999-multibots.

## Ключевые особенности

- **Провайдер**: Fal.ai
- **ID модели**: `fal-ai/nano-banana-pro`
- **Цена**: $0.0398 за изображение (25 изображений за $1)
- **Возможности**:
  - Отличный фотореализм
  - Превосходная отрисовка текста
  - Высококачественная генерация изображений
  - Поддержка множества соотношений сторон
  - Разрешение до 4K
  - Естественная эстетика

## Поддерживаемые параметры

### Соотношения сторон
- `21:9` - Ультраширокий формат
- `16:9` - Широкоэкранный
- `3:2` - Классическое фото
- `4:3` - Стандартный
- `5:4` - Портрет
- `1:1` - Квадрат (по умолчанию)
- `4:5` - Портрет
- `3:4` - Портрет
- `2:3` - Портрет
- `9:16` - Вертикальный

### Разрешения
- `1K` - Стандартное качество (по умолчанию)
- `2K` - Высокое качество
- `4K` - Ультравысокое качество

### Форматы вывода
- `jpeg` - Сжатый формат
- `png` - Формат без потерь (по умолчанию)
- `webp` - Современный формат

## Использование

### В визарде Text-to-Image

Пользователи могут выбрать "Nano Banana Pro" из меню выбора модели в визарде генерации изображений.

### Через UniversalProviderManager

```typescript
import { UniversalProviderManager } from '@/services/UniversalProviderManager'

const manager = new UniversalProviderManager()

const result = await manager.generateImage('nano-banana-pro', {
  prompt: 'Красивый закат над горами',
  numImages: 1,
  style: '16:9', // соотношение сторон
  userId: 'user123',
})
```

### Прямой вызов API

```typescript
import { generateNanoBananaPro } from '@/services/generateNanoBananaPro'

const result = await generateNanoBananaPro({
  prompt: 'Красивый закат над горами',
  numImages: 1,
  aspectRatio: '16:9',
  resolution: '2K',
  outputFormat: 'png',
  telegramId: '123456789',
})
```

## Точки интеграции

### 1. UniversalProviderManager
- Добавлена в реестр моделей изображений
- Интегрирована с провайдером Fal

### 2. Конфигурация цен
- Добавлена в `imageModelPrices.ts`
- Стоимость: $0.0398 за изображение
- Конвертируется в звёзды через `calculateFinalImageCostInStars()`

### 3. Генерация Text-to-Image
- Интегрирована в `generateTextToImageDirect.ts`
- Специальная обработка для провайдера Fal.ai
- Поддерживает все стандартные функции
