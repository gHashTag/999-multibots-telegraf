# 🤖 Инструкция по тестированию Instagram парсинга в Telegram боте

## 🚀 Быстрый старт

### 1. **Запуск бота локально**
```bash
# Установка зависимостей (если еще не установлены)
npm install

# Запуск в режиме разработки
npm run dev

# Или запуск через bun
bun run dev
```

### 2. **Настройка переменных окружения**
Убедитесь что в `.env` файле настроены:
```bash
# Токены ботов
BOT_TOKEN=your_bot_token_here

# База данных
NEON_DATABASE_URL=your_db_url_here

# Inngest (необязательно для dev)
INNGEST_EVENT_KEY=your_key_for_production

# Режим
NODE_ENV=development
```

1. Запустите бота локально: `npm run dev`
2. Найдите своего бота в Telegram
3. Отправьте `/start` для инициализации

```

```

**Ожидаемый результат для админа:**

1. Нажмите **🚀 Быстрый тест**

Следите за консолью, где запущен бот:

### **Шаг 5: Проверка уведомлений**

- Проверьте логи AI сервера для отладки

## 🔍 Отладка проблем

### **Проблема: "❌ Команда доступна только администраторам"**
**Решение:**
1. Проверьте что ваш Telegram ID в `ADMIN_IDS_ARRAY`
2. Перезапустите бота после изменения конфигурации

### **Проблема: "❌ Ошибка при запуске анализа"**
**Возможные причины:**
1. **INNGEST_EVENT_KEY не настроен** - нормально для development
2. **Сетевые проблемы** - проверьте интернет соединение
3. **Неверная конфигурация** - проверьте `src/inngest_app/client.ts`

**Отладка:**
```bash
# Проверьте конфигурацию Inngest
bun -e "console.log(await import('./src/inngest_app/client.ts'))"

# Проверьте переменные окружения
echo $NODE_ENV
echo $INNGEST_EVENT_KEY
```

### **Проблема: "Событие отправлено, но нет уведомления"**
**Что проверить:**
1. **Логи AI сервера** - событие должно появиться там
2. **Функция instagramScraperV2** - работает ли на сервере
3. **База данных** - есть ли подключение
4. **RapidAPI ключи** - настроены ли на сервере
