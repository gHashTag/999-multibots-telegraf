# 🚀 Руководство по развертыванию в продакшн

Этот документ описывает единый и правильный способ развертывания приложения на продакшн-сервере.

## 1. Предварительные требования

1.  **Доступ по SSH:** У вас должен быть настроен доступ к серверу `root@212.86.115.30` с помощью вашего SSH-ключа `~/.ssh/zomro`.
2.  **Актуальный `.env` файл:** Все необходимые ключи и переменные окружения должны быть в вашем локальном файле `.env`. Скрипт деплоя **не переносит** `.env` файл на сервер. Если на сервере отсутствуют нужные переменные, их нужно добавить туда вручную.

## 2. Процесс развертывания

Для развертывания всех изменений в продакшн используется **только одна команда**. Ее нужно выполнить из корня проекта.

```bash
npm run deploy
```

Эта команда автоматически выполнит все необходимые шаги:
- Создаст коммит с вашими последними изменениями (если они есть).
- Отправит изменения в `production` ветку на GitHub.
- Подключится к серверу и выполнит следующие действия:
    - Загрузит последние изменения из GitHub.
    - Остановит и удалит старый Docker-контейнер.
    - Пересоберет Docker-образ **без использования кеша**, чтобы гарантированно применить все изменения в коде.
    - Запустит новый контейнер со всеми 10 ботами.

## 3. Проверка статуса после развертывания

Скрипт автоматически выведет статус запущенного контейнера и последние 20 строк логов.

Если вам нужно проверить логи или статус позже, используйте следующие команды:

- **Проверить статус контейнера:**
  ```bash
  ssh -i ~/.ssh/zomro root@212.86.115.30 'docker ps | grep 999-multibots'
  ```

- **Посмотреть последние 100 строк логов:**
  ```bash
  ssh -i ~/.ssh/zomro root@212.86.115.30 'docker logs 999-multibots --tail 100'
  ```
