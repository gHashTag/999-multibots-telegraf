# 🔍 Robokassa Error 29 Troubleshooting

**Проблема**: Error code 29 - "No payment methods available"
**Причина**: Invalid Signature (по документации)
**Учетные данные**:
- `MERCHANT_LOGIN=neuroblogger`
- `ROBOKASSA_PASSWORD_1=GhfqLJR79Do9Zvans16G`
- `ROBOKASSA_PASSWORD_2=w31s8DPWPITH5dh6eTTL`
- `TEST_PASSWORD1=Uw2c9CgfPXYx7KLmNp`

## ✅ Что уже проверено и исправлено:

1. ✅ **InvId generation**: Исправлено с random на `Date.now() % 2147483647`
2. ✅ **Signature formula**: Используем правильную `MerchantLogin:OutSum:InvId:Password1`
3. ✅ **MD5 hash**: Правильно применяется `.toUpperCase()`
4. ✅ **Minimum amount**: Убрали 10 RUB, тестировали 100, 500, 1000 RUB
5. ✅ **Cyrillic characters**: Тестировали с латиницей и без Description
6. ✅ **ResultURL**: Тестировали с и без ResultURL параметра
7. ✅ **Test mode**: Тестировали с IsTest=1 и TEST_PASSWORD1

**РЕЗУЛЬТАТ**: Всё равно Error 29

## 🎯 ЧТО НУЖНО ПРОВЕРИТЬ В ЛИЧНОМ КАБИНЕТЕ ROBOKASSA

### Войти в ЛК: https://partner.robokassa.ru/

### 1. Статус магазина "neuroblogger"

- [ ] **Магазин активирован?**
  - Путь: Магазины → neuroblogger → Статус
  - Должно быть: "Активен" ✅
  - Если "Не активен" или "На модерации" ❌ → Активировать

### 2. Технические настройки (КРИТИЧНО!)

- [ ] **Password #1 совпадает?**
  - Путь: Магазины → neuroblogger → Технические настройки
  - Вкладка: "Пароли"
  - Password #1 (боевой): `GhfqLJR79Do9Zvans16G`
  - Если НЕ совпадает → Скопировать правильный пароль

- [ ] **Password #2 совпадает?**
  - Password #2 (боевой): `w31s8DPWPITH5dh6eTTL`
  - Если НЕ совпадает → Скопировать правильный пароль

- [ ] **TEST_PASSWORD1 совпадает?**
  - Вкладка: "Тестовые пароли"
  - Test Password #1: `Uw2c9CgfPXYx7KLmNp`
  - Если НЕ совпадает → Скопировать правильный пароль

### 3. Способы оплаты

- [ ] **Подключены методы оплаты?**
  - Путь: Магазины → neuroblogger → Способы оплаты
  - Должны быть включены:
    - ✅ Банковские карты (Visa, MasterCard, МИР)
    - ✅ СБП (Система быстрых платежей)
    - ✅ Электронные кошельки
  - Если ничего не включено → Подключить методы

### 4. Минимальная сумма платежа

- [ ] **Минимальная сумма для магазина**
  - Путь: Магазины → neuroblogger → Настройки
  - Проверить: "Минимальная сумма платежа"
  - Если > 500 RUB → Уменьшить до 100 RUB или меньше

### 5. Режим работы

- [ ] **Боевой режим включен?**
  - Путь: Магазины → neuroblogger → Настройки
  - Проверить: "Режим работы"
  - Должно быть: "Боевой" для production
  - "Тестовый" - только для тестирования

### 6. Result URL настройки

- [ ] **Result URL разрешен?**
  - Путь: Магазины → neuroblogger → Технические настройки
  - Проверить настройку: "Использовать Result URL"
  - Если отключена → Включить
  - Добавить URL: `https://three-head-dragon.shop/payment-success`

### 7. Ограничения и лимиты

- [ ] **Нет блокировок магазина?**
  - Путь: Главная → Уведомления
  - Проверить нет ли предупреждений о:
    - Блокировке магазина
    - Превышении лимитов
    - Требовании верификации

## 🔧 ЧТО ДЕЛАТЬ ПОСЛЕ ПРОВЕРКИ ЛК

### Сценарий 1: Пароли НЕ совпадают

```bash
# 1. Обновить .env на локальной машине
# Скопировать правильные пароли из ЛК Robokassa

# 2. Обновить .env на production сервере
ssh -i ~/.ssh/zomro root@212.86.115.30
cd /root/bot-farm
nano .env
# Вставить правильные ROBOKASSA_PASSWORD_1 и ROBOKASSA_PASSWORD_2

# 3. Перезапустить Docker контейнер
docker restart 999-multibots

# 4. Создать тестовую ссылку локально
npx tsx tests/test-robokassa-latin-only.ts

# 5. Проверить в браузере
```

### Сценарий 2: Магазин не активирован

```
1. В ЛК Robokassa: Активировать магазин
2. Дождаться подтверждения (может занять до 24 часов)
3. После активации - повторить тесты
```

### Сценарий 3: Не подключены способы оплаты

```
1. В ЛК Robokassa: Подключить способы оплаты
2. Включить как минимум:
   - Банковские карты
   - СБП
3. Сохранить изменения
4. Повторить тесты
```

### Сценарий 4: Высокая минимальная сумма

```
1. В ЛК Robokassa: Снизить минимальную сумму до 100 RUB
2. Сохранить изменения
3. Повторить тесты с 100 RUB
```
