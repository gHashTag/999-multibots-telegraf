## 💡 РЕКОМЕНДАЦИИ

### Для инвесторов:

1. **Чистые доходы** от пользователей (без бонусов/тестов)

#### ❌ ЧТО НЕ ПОКАЗЫВАТЬ:

2. Тестовые операции
3. Системные операции

### Технические исправления:

#### 🔧 ПРИОРИТЕТ 1 - КЛАССИФИКАЦИЯ
```sql
-- Создать новую категорию для больших расходов
CREATE TABLE business_expenses (
  id BIGSERIAL PRIMARY KEY,
  bot_name TEXT NOT NULL,
  amount DECIMAL NOT NULL,
  currency TEXT NOT NULL,
  category TEXT NOT NULL, -- 'AI_TRAINING', 'HOSTING', 'ADVERTISING', etc.
  description TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Перенести записи >1000 STARS из MONEY_OUTCOME в business_expenses
```

#### 🔧 ПРИОРИТЕТ 2 - ОЧИСТКА ДАННЫХ
```sql
-- Удалить дубликаты
DELETE FROM payments_v2
WHERE id NOT IN (
  SELECT DISTINCT ON (bot_name, amount, description) id
  FROM payments_v2
  ORDER BY bot_name, amount, description, created_at
);

-- Отметить фейковые записи
UPDATE payments_v2
SET is_fake = true
WHERE description ILIKE '%bonus%'
   OR description ILIKE '%test%'
   OR description ILIKE '%system%'
   OR description = 'SUBSCRIPTION_PURCHASE'
   OR description = 'AI_VIDEO_GENERATION';
```

#### 🔧 ПРИОРИТЕТ 3 - НОВЫЕ МЕТРИКИ
1. **Чистая прибыль** = Доходы - Расходы
2. **Маржинальность** = (Доходы - Расходы) / Доходы
3. **ROI по ботам** = Прибыль бота / Инвестиции
4. **Качество данных** = % реальных записей
