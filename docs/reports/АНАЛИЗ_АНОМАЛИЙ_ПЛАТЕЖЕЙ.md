## 💡 ПЛАН ОЧИСТКИ

### Шаг 1: Создать backup
```sql
CREATE TABLE payments_v2_backup AS SELECT * FROM payments_v2;
```

### Шаг 2: Создать таблицу для расходов
```sql
CREATE TABLE business_expenses (
  id BIGSERIAL PRIMARY KEY,
  bot_name TEXT NOT NULL,
  amount DECIMAL NOT NULL,
  currency TEXT NOT NULL,
  category TEXT NOT NULL,
  description TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Шаг 3: Перенести большие расходы
```sql
INSERT INTO business_expenses (...)
SELECT bot_name, amount, currency,
  CASE
    WHEN description ILIKE '%тренировк%' THEN 'AI_TRAINING'
    WHEN description ILIKE '%реклам%' THEN 'ADVERTISING'
    WHEN description ILIKE '%хостинг%' THEN 'HOSTING'
    WHEN description ILIKE '%API%' THEN 'API_TOKENS'
    ELSE 'OTHER'
  END as category,
  description, created_at
FROM payments_v2
WHERE type = 'MONEY_OUTCOME' AND currency = 'STARS' AND ABS(amount) > 1000;
```

### Шаг 4: Удалить аномалии
```sql
-- Удалить перенесенные записи
DELETE FROM payments_v2 WHERE type = 'MONEY_OUTCOME' AND currency = 'STARS' AND ABS(amount) > 1000;

-- Удалить дубликаты
DELETE FROM payments_v2 p1 USING payments_v2 p2
WHERE p1.ctid < p2.ctid AND p1.bot_name = p2.bot_name
  AND p1.amount = p2.amount AND p1.description = p2.description;

-- Удалить фейковые данные
DELETE FROM payments_v2 WHERE
  (description ILIKE '%bonus%' OR description ILIKE '%бонус%') OR
  (description ILIKE '%test%' OR description ILIKE '%тест%') OR
  (description ILIKE '%system%' OR description ILIKE '%система%') OR
  description IN ('SUBSCRIPTION_PURCHASE', 'AI_VIDEO_GENERATION') OR
  type = 'REFUND';

-- Удалить нулевые суммы
DELETE FROM payments_v2 WHERE amount = 0;
```

### Шаг 5: Проверить результат
```sql
SELECT COUNT(*) FROM payments_v2;  -- Должно быть ~1,202
SELECT COUNT(*) FROM business_expenses;  -- Должно быть 9
```

1. **Для инвесторов показывать:**
   - Чистые доходы (без фейка)
   - Расходы по категориям (AI, реклама, хостинг)
   - ROI и маржинальность
   - Динамику роста

2. **НЕ показывать инвесторам:**
