## 📊 СХЕМА ТАБЛИЦЫ

```sql
CREATE TABLE public.payments_v2 (
  id serial NOT NULL,
  telegram_id bigint NOT NULL,
  payment_date timestamp with time zone NOT NULL DEFAULT now(),
  amount numeric NOT NULL DEFAULT 0,
  description text NULL,
  metadata jsonb NULL DEFAULT '{}'::jsonb,
  stars numeric(10, 2) NOT NULL DEFAULT 0,
  currency character varying(10) NOT NULL DEFAULT 'STARS',
  inv_id character varying(100) NULL,
  invoice_url text NULL,
  status payment_status NOT NULL,
  type operation_type NOT NULL,
  service_type text NULL,
  operation_id text NULL,
  bot_name character varying(255) NOT NULL,
  language character varying(2) NULL DEFAULT 'ru',
  payment_method text NULL,
  subscription_type text NULL,
  is_system_payment boolean NULL DEFAULT false,
  created_at timestamp with time zone NOT NULL DEFAULT now(),
  cost numeric NULL,
  category simple_transaction_category NOT NULL DEFAULT 'REAL',
  model_name text NULL,
  corporate_account_id uuid NULL,
  employee_allocation_id uuid NULL,
  transaction_context character varying(30) NULL DEFAULT 'PERSONAL',
  is_test boolean NULL DEFAULT false
)
```

## 💰 ПРАВИЛЬНАЯ ЛОГИКА РАСЧЕТОВ

### ДОХОДЫ (MONEY_INCOME + COMPLETED):
```typescript
if (type === 'MONEY_INCOME' && status === 'COMPLETED') {
  // Для валюты STARS используем поле 'stars'
  // Для остальных валют используем поле 'amount'
  if (currency === 'STARS') {
    income += stars;
  } else {
    income += amount;
  }
}
```

### РАСХОДЫ (MONEY_OUTCOME + COMPLETED):
```typescript
if (type === 'MONEY_OUTCOME' && status === 'COMPLETED') {
  // Для STARS используем поле 'stars'
  // Для остальных используем поле 'amount'
  if (currency === 'STARS') {
    costs += stars;
  } else {
    costs += amount;
  }
}
```

### ИСКЛЮЧЕНИЯ:
- `is_test = true` - исключаем из анализа
- `category = 'TEST'` - исключаем из анализа
- `status != 'COMPLETED'` - исключаем (только завершенные)

## 🔍 ФИЛЬТРЫ ПО ПОЛЯМ

### По статусу:
- ✅ COMPLETED - завершенные
- ❌ FAILED - неудачные
- ⏳ PENDING - в ожидании
- ⚠️ CANCELLED - отмененные

### По типу:
- 💰 MONEY_INCOME - доходы (пополнения, оплата услуг)
- 💸 MONEY_OUTCOME - расходы (траты, вывод средств)

### По категории:
- REAL - реальные операции
- TEST - тестовые операции
- SYSTEM - системные операции

### По контексту:
- PERSONAL - персональные
- CORPORATE_FUNDING - корпоративное финансирование
- CORPORATE_ALLOCATION - корпоративное распределение
- CORPORATE_USAGE - корпоративное использование

### По валюте:
- RUB - российские рубли
- STARS - звезды (Telegram)
- XTR - внутренняя валюта
- USD - доллары США
- EUR - евро

### По языку:
- ru - русский
- en - английский
