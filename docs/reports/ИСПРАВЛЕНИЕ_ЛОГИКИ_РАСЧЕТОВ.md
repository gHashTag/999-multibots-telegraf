## 🎯 ПРОБЛЕМА

Пользователь указал, что доходы 34,600,875₽ не могут быть правильными. Основные ошибки:
1. **Неправильное использование полей** - использовалось только `amount`, игнорировалось поле `stars`
2. **Неправильная логика расчетов** - MONEY_OUTCOME с положительными суммами считались доходами
3. **Нет фильтрации по статусу** - использовались все записи, включая не завершенные

---

## ✅ РЕШЕНИЕ

### 1. **Правильная логика использования полей:**

```typescript
// Для валюты STARS используем поле 'stars'
// Для остальных валют используем поле 'amount'
const amount = row.currency === 'STARS'
  ? parseFloat(row.stars) || 0
  : parseFloat(row.amount) || 0;
```

### 2. **Правильная логика расчетов:**

```typescript
// ДОХОДЫ - только MONEY_INCOME
.filter((row: any) => row.type === 'MONEY_INCOME')

// РАСХОДЫ - только MONEY_OUTCOME
.filter((row: any) => row.type === 'MONEY_OUTCOME')
```

### 3. **Фильтрация данных:**

```typescript
// Из базы данных:
.filter((row: any) => row.status === 'COMPLETED' && !row.is_test)

// Из JSON файлов (гибкая фильтрация):
.filter((row: any) => {
  if (row.status && row.status !== 'COMPLETED') return false;
  if (row.is_test === true) return false;
  return true;
})
```
