## 📋 СОДЕРЖИМОЕ КАЖДОГО ЛИСТА

### 1️⃣ **💰 ОБЩАЯ СТАТИСТИКА**
```
Блок с ключевыми показателями:
├── 💰 Доходы (всего)
├── 💰 Доходы в рублях (RUB)
├── 💰 Доходы в звездах (STARS)
├── 💰 Доходы в XTR
├── 💸 Расходы (себестоимость)
├── ⚖️ Прибыль
├── 📈 Рентабельность
└── 📊 Количество операций
```

### 2️⃣ **💸 ДЕТАЛИЗАЦИЯ РАСХОДОВ ПО ТИПАМ**
```
Таблица с разбивкой:
├── №
├── Тип расхода (название на русском)
├── Оригинал (₽) - исходная сумма
├── Себестоимость (₽) - нормализованная
├── Операций - количество
└── Валюты - разбивка по валютам

Пример строки:
│ 1 │ Training модели │ 70,556 │ 10,500 │ 7 │ 39,000★, 30 XTR │
```

**Типы расходов:**
- **Training модели** - обучение персональных моделей ИИ
- **Video generation** (System) - генерация видео (Kling, Sora, Seedance)
- **NeuroPhoto** (Internal) - генерация изображений
- **image-to-video** - генерация видео из изображения
- **text_to_image** - генерация изображений из текста
- **flux_kontext** - контекстная генерация
- **image_upscaler** - увеличение качества
- **lip_sync** - синхронизация губ
- **ai_reels** - AI Reels
