## 🎨 Преимущества новой схемы

### 1. 🔥 Простота
**До**: "В dev это `BOT_TOKEN_TEST_1`, а в prod это `BOT_TOKEN_1`... постой, или наоборот?"
**После**: "Везде `BOT_TOKEN_1`-`BOT_TOKEN_N`. Просто!"

### 2. 📈 Масштабируемость
Нужно добавить 11-й бот?
```bash
# Просто добавь в Infisical:
BOT_TOKEN_11 = <новый_токен>
```

### 3. 🔄 Единообразие кода
**До**: Два разных массива, разная логика для dev/prod
**После**: Один цикл for, одна логика для всех

### 4. 🛡️ Изоляция окружений
- Dev: свои токены `BOT_TOKEN_1-2`
- Staging: свои токены `BOT_TOKEN_1-10`
- Prod: свои токены `BOT_TOKEN_1-10`

Одинаковые имена, разные значения = чистая архитектура!

