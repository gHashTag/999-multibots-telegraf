## 📋 ПОРЯДОК ВЫПОЛНЕНИЯ КОМАНД:

### 1️⃣ Создать backup
```sql
CREATE TABLE payments_v2_backup AS SELECT * FROM payments_v2;
```
**Проверка:** `SELECT COUNT(*) FROM payments_v2_backup;` (должно быть 16217)

### 2️⃣ Создать таблицу business_expenses
```sql
CREATE TABLE IF NOT EXISTS business_expenses (...);
```

### 3️⃣ Перенести большие расходы
```sql
INSERT INTO business_expenses (...);
```
**Проверка:** `SELECT COUNT(*) FROM business_expenses;` (должно быть 11)

### 4️⃣ Удалить перенесенные записи
```sql
DELETE FROM payments_v2 WHERE type = 'MONEY_OUTCOME' AND currency = 'STARS' AND ABS(amount) > 1000;
```

### 5️⃣ Добавить колонку is_test
```sql
ALTER TABLE payments_v2 ADD COLUMN IF NOT EXISTS is_test BOOLEAN DEFAULT FALSE;
```

### 6️⃣ Пометить тестовые данные
```sql
UPDATE payments_v2 SET is_test = TRUE WHERE description ILIKE '%TEST_DATA%';
```
**Проверка:** `SELECT COUNT(*) FROM payments_v2 WHERE is_test = TRUE;`

### 7️⃣ Удалить нулевые суммы
```sql
DELETE FROM payments_v2 WHERE amount = 0;
```

### 8️⃣ Удалить дубликаты
```sql
-- Удаляет только дубликаты с одинаковыми датой+временем
```

### 9️⃣ Проверка результата
```sql
-- Показать статистику

SELECT COUNT(*) FROM business_expenses;
```
