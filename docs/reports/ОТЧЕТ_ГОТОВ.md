**Содержание**:

### 📝 2. SQL скрипт для получения данных
**Файл**: `sql-scripts/01-get-all-payments.sql`

**Что делает**:
- Извлекает ВСЕ транзакции из payments_v2
- Анализирует по валютам (XTR, RUB, STARS)
- Находит топ-50 активных пользователей
- Группирует по способам оплаты
- Показывает динамику по месяцам

### 🎨 3. Скрипт генерации отчета
**Файл**: `scripts/create-beautiful-report.js`

**Возможности**:
- Генерирует Excel с 4 листами
- Красивое форматирование с эмодзи
- Автоматические расчеты
- Готов к замене на реальные данные

## 🚀 Что нужно сделать для получения РЕАЛЬНЫХ данных

### Вариант 1: Быстро (5 минут)
1. Открыть Supabase: https://supabase.com/dashboard/project/fbgmxbvzwgxfkagxkmqc
2. Выполнить `sql-scripts/01-get-all-payments.sql`
3. Скопировать результаты

5. Запустить: `node scripts/create-beautiful-report.js`
