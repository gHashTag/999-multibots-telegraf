## 📊 СВОДКА ПО ТИПАМ КНОПОК

В системе используются **2 типа кнопок**:

### 1️⃣ **INLINE КНОПКИ** (Callback Data + Action Handlers)
- **Регистрация:** `.action('callback_data', handler)`
- **Место:** Внутри сцен (`Scenes.WizardScene`)
- **Характеристики:** Привязаны к сообщению, используют `callback_data`
- **Количество:** 11 файлов с action handlers
- **Примеры:**
  - `go_to_subscription_scene` (кнопка "💫 Оформить подписку")
  - `ai_photoshop_*` (AI Photoshop сцена)
  - `flux_*` (FLUX Kontext сцена)
  - `morphing_*` (морфинг)
  - `download_excel_report`, `back_to_menu` (баланс)

### 2️⃣ **KEYBOARD КНОПКИ** (Text + Hears Handlers)
- **Регистрация:** `.hears('text', handler)`
- **Место:** Глобально в `hearsHandlers.ts` + внутри некоторых сцен
- **Характеристики:** Глобальные, работают везде, используют текст кнопки
- **Количество:** 9 файлов с hears handlers
- **Примеры:**
  - `🏠 Главное меню` / `🏠 Main menu`
  - `❓ Справка` / `❓ Help`
  - `1️⃣`, `2️⃣`, `3️⃣`, `4️⃣` (количество изображений)
  - Уровни меню: `levels[1-12]`, `levels[100-108]`
