# 🔧 ИНСТРУКЦИЯ: РАБОТА С ТЕСТОВЫМИ ДАННЫМИ

## 📋 ЗАДАЧА
Фейковые данные (System Grant, BONUS, Миграция) используются для **тестирования группой QA**. Нужно их систематизировать и сделать удобными для анализа.

---

## ✅ РЕШЕНИЕ

### 1️⃣ **СИСТЕМАТИЗАЦИЯ**
Все фейковые данные переименованы в единое название:
```
TEST_DATA: System/Bonus/Testing | TAG:TEST_DATA
```

### 2️⃣ **КЛАССИФИКАЦИЯ**
- **🔧 ТЕСТОВЫЕ ДАННЫЕ** - для группы QA (System Grant, BONUS, Миграция)
- **✅ РЕАЛЬНЫЕ ДАННЫЕ** - платежи от пользователей (Telegram, Robokassa)

   - Создание индексов и VIEW

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### **Шаг 1: Очистить данные в Supabase**
```sql
-- Выполнить в Supabase SQL Editor
\i CLEAN_TEST_DATA.sql
```

**Что делает:**
- ✅ Переименовывает все фейковые данные в "TEST_DATA"
- ✅ Добавляет тег | TAG:TEST_DATA
- ✅ Создает индекс для быстрого поиска
- ✅ Создает VIEW для удобного просмотра

### **Шаг 2: Работать с Excel**
1. Открыть `АНАЛИЗ_С_ТЕСТОВЫМИ_ДАННЫМИ_И_ФИЛЬТРАМИ.xlsx`
2. Включить фильтры (данные → Фильтр)
3. Фильтровать по колонкам:
   - "Для тестировщиков" - показать только нужные боты
   - "Тестовые" - показать только тестовые операции
   - "Статус" - выбрать прибыльные/убыточные

### **Шаг 3: Анализировать данные**
```
🔧 ТЕСТОВЫЕ ДАННЫЕ (оранжевые):
  - neuro_blogger_bot: 2,080 тестовых транзакций
  - LeeSolarbot: 208 тестовых транзакций

✅ РЕАЛЬНЫЕ ДАННЫЕ (зеленые):
  - MetaMuse_Manifest_bot: 4,080 реальных транзакций
  - HaimGroupMedia_bot: 357 реальных транзакций
```

## 🎯 БЫСТРЫЕ ЗАПРОСЫ В SUPABASE

### **Просмотр тестовых данных:**
```sql
SELECT * FROM test_data_summary;
```

### **Просмотр реальных данных:**
```sql
SELECT * FROM real_data_summary;
```

### **Поиск по боту:**
```sql
SELECT * FROM payments_v2 
WHERE bot_name = 'neuro_blogger_bot' 
  AND description LIKE '%TEST_DATA%';
```

### **Подсчет тестовых транзакций:**
```sql
SELECT bot_name, COUNT(*) as test_count
FROM payments_v2
WHERE description LIKE '%TEST_DATA%'
GROUP BY bot_name
ORDER BY test_count DESC;
```

## ⚡ ПРЕИМУЩЕСТВА НОВОЙ СИСТЕМЫ

1. **Единое название** - не нужно помнить все варианты "System Grant", "BONUS", "Миграция"
2. **Цветовая маркировка** - сразу видно тестовые и реальные данные
3. **Автофильтры** - легко анализировать любые срезы данных
4. **VIEW в Supabase** - быстрые запросы без сложных WHERE
5. **Индекс** - быстрый поиск тестовых данных
