## 🔍 КОРЕНЬ ПРОБЛЕМЫ

**Архитектурная особенность Telegraf Scenes:**

1. **Scene handlers перехватывают ВСЕ сообщения** когда пользователь находится внутри сцены
2. **Глобальные обработчики (hearsHandlers.ts) НЕ выполняются** пока пользователь в сцене
3. **Универсальный обработчик `bot.hears(/.*/)` не спасает** - он просто не вызывается

Это фундаментальное ограничение архитектуры Telegraf, а не баг в коде.

```typescript
// ✅ КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Проверяем кнопки меню
try {
  const { NAVIGATION_BUTTONS } = await import('@/navigation/unified-navigation.config')
  const button = NAVIGATION_BUTTONS.find(btn => btn.ru === messageText || btn.en === messageText)

  if (button) {
    // Это кнопка меню! Выходим из сцены
    logger.info('🔄 Menu button detected, exiting scene', { telegramId, buttonText })
    return ctx.scene.leave()
  }
} catch (error) {
  // При ошибке - продолжаем обычную обработку
  logger.warn('Failed to import NAVIGATION_BUTTONS', { error })
}
```

### Ключевые особенности:
1. **Динамический импорт** - не увеличивает размер бандла
2. **Graceful degradation** - при ошибке импорта сцена продолжает работать
3. **Подробное логирование** - для диагностики в production
4. **Совместимость с RU/EN** - проверяет оба языка кнопок
