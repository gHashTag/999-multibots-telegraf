# CRM лид-магнит: портрет 9:16 из фото клиента — 2026-09-13

Спецификация (первоисточник логики, английский): `t27/specs/automation/crm-lead-magnet.t27`.
Этот файл — локализованная сводка и урок; при расхождении прав спек.

## Что сделано

- `crm_deliver_photo` по умолчанию работает в режиме **подарка** (`gift=true`): аватарка человека
  из Telegram перерисовывается в вертикальный портрет 9:16 (img2img), получатель **не платит**,
  генерацию оплачивает владелец со своего кошелька операцией `gpt_image_edit` (12 токенов).
  Старое поведение (платно, по описанию, списание с получателя при нажатии) — `gift=false`.
- Источник фото: сначала сессия владельца (GramJS `downloadProfilePhoto`), потом бот-API
  `getUserProfilePhotos`. Нет фото → text-to-image 1080×1920, в ответе `source: "по описанию"`.
- Модель: Kie `gpt-image-2-5-flare-image-to-image`, `resolution: 1K`, поле `input_urls`
  (у `nano-banana-edit` — `image_urls`; форма входа выбирается по модели, `editInputFor`).
- Промпт: сначала «тот же человек» (что сохранить), потом сцена владельца, потом кадр
  (лицо в центральной трети, без текста). Порядок важен: img2img-модели сильнее весят начало.
- Подпись по умолчанию: имя, «сделал ИИ-ассистент», формат 9:16, один вопрос; без цены и ссылок.
- Карточка предложения несёт `gift: true`; при отправке касание пишется как `written` с префиксом
  `подарок в личке: ` (не покупка). `sellerSendsSince` учитывает и этот префикс.
- Клавиатуры CRM в боте: **не больше двух кнопок в ряд** (`fit()`, `MAX_BUTTONS_PER_ROW = 2`,
  `hubRows()` вместо `hubRow()`); ratchet-тест в `src/__tests__/navigation/crmMenu.test.ts`.
  Кнопка шага `deliver` — «🎁 Фото 9:16».

## Статус утверждений

- Контракт и цена Kie GPT Image 2.5 (1K = $0.03) — **задокументированы** по docs.kie.ai и
  публичному прайс-листу 13.09.2026, **живой прогон из этого кода не делался**.
- `downloadProfilePhoto` через сессию владельца — по типам GramJS; в проде не проверено.
- В `KIE_MODELS` (каталог живых замеров) модель **не добавлена** намеренно: там только промеренные.

## Уроки

1. Цену новой модели заводить отдельной операцией в `OPERATION_COST_USD`, а не подменять
   `image_generate`: ценовые ratchet-тесты требуют, чтобы каждая операция была в прайсе.
2. Форма входа Kie различается по моделям даже в одном виде (img2img) — выбирать по имени модели.
3. Три кнопки в ряд с эмодзи режутся на телефоне; правило ширины лучше держать в одной точке
   (`fit`) и ratchet-тесте, чем полагаться на каждого автора клавиатуры.
