## 2. Слабые места (аудит)

1. **Планировщик = «просто крон».** Карточки крона не объявляют `TZ`, `JITTER`, `OVERLAP`,
   `CATCHUP`; в день перевода часов крон «may run zero, one, or two times»
   ([Inngest](https://www.inngest.com/docs/guides/scheduled-functions)). [известно]
2. **Одна коробка Inngest.** SQLite «does not support scaling beyond a single node»; при падении
   сервиса воркфлоу стоят ([Inngest self-hosting](https://www.inngest.com/docs/self-hosting)).
   Ретеншн ранов не задан — таблицы растут. [известно]
3. **Публичные поверхности без своей аутентификации.** Speaches `/docs` и `/openapi.json`
   открыты даже при `api_key` ([Speaches](https://speaches.ai/configuration/)); у llama.cpp
   `GET /props` не проверяет ключ ([llama.cpp server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server)).
   Сейчас оба сервиса доступны только по private network Railway — это и есть защита. [известно]
4. **Дрейф спека и кода.** Главная слабость SDD-инструментов: «the spec does not update itself»
   ([обзор](https://levelop.dev/blog/spec-driven-development-tools-compared)); у нас
   `functions.md` генерируется из manifest, а не из `.t27`. [вопрос]
5. **Бюджеты не в спеке.** Мультиагент тратит ~15× токенов чата
   ([Anthropic](https://www.anthropic.com/engineering/multi-agent-research-system)); у CrewAI
   `max_iter=25` — «the most common cost leak». У Queen→Bee лимитов итераций в карточках нет. [известно]
6. **Гейты, которые можно выключить опечаткой.** OpenSpec #1867/#1869: изменение «green-lit by
   status/apply, rejected by validate» ([issues](https://github.com/Fission-AI/OpenSpec/issues)).
   Любой наш гейт обязан быть fail-closed. [известно]
7. **CPU-инференс медленный.** [измерено] Qwen3-VL-2B Q8 на Railway: промпт 17–30 ток/с,
   генерация ~1,5–3 ток/с; два прогона ролика уперлись в 300 с. STT на CPU считать по RTFx
   (faster-whisper 5–6× реального времени на десктопном CPU
   ([ssdnodes](https://www.ssdnodes.com/learn/self-hosted-speech-to-text-and-tts))), ~1 %
   транскриптов содержат выдуманные фразы ([arXiv 2503.09905](https://arxiv.org/html/2503.09905v1)).
8. **Платформенный риск.** AutoGen заморожен ([#7066](https://github.com/microsoft/autogen/discussions/7066)),
   Inngest OSS под SSPL ([LICENSE](https://github.com/inngest/inngest/blob/main/LICENSE.md)).
   Планировщик надо держать за интерфейсом `.t27`, чтобы смена движка не переписывала каталоги.
9. **Владельческие блокеры** (см. раздел 5): CI 999 стоит из-за биллинга GitHub Actions,
   34 уязвимости Dependabot, невалидный `OPENAI_API_KEY`, мёртвая GramJS-сессия. [вопрос]
