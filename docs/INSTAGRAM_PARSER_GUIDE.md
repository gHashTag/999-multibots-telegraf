# 📱 Instagram Парсер - Инструкция по использованию

## 🎯 Что это такое?
Instagram парсер - это инструмент для сбора рилсов (коротких видео) из Instagram по:
- **Username конкурента** - собирает рилсы с конкретного аккаунта
- **Хештегу** - собирает популярные рилсы по хештегу

## 💰 Сколько это стоит?

| Количество рилсов | Стоимость в звездах ⭐ |
|-------------------|----------------------|
| 10 рилсов         | 3 ⭐                  |
| 25 рилсов         | 8 ⭐                  |
| 50 рилсов         | 15 ⭐                 |
| 100 рилсов        | 30 ⭐                 |
| 200 рилсов        | 55 ⭐ (скидка!)       |

## 🚀 Как пользоваться?

### Способ 1: Через кнопку в меню
1. Откройте главное меню бота
2. Найдите кнопку **"📱 Instagram Парсер"** (доступна только для авторизованных пользователей)
3. Нажмите на нее

### Способ 2: Через команду
Отправьте команду: `/instagram`

### Далее:
1. **Выберите тип парсинга:**
   - 👤 Парсинг конкурента - для сбора рилсов с конкретного аккаунта
   - #️⃣ Парсинг по хештегу - для сбора популярных рилсов по теме

2. **Введите цель:**
   - Для аккаунта: username без @ (например: `nike`, `adidas`)
   - Для хештега: слово без # (например: `fitness`, `travel`)

3. **Выберите количество рилсов:**
   - От 10 до 200 штук
   - Чем больше берете - тем выгоднее цена за штуку

4. **Подтвердите оплату:**
   - Проверьте баланс
   - Подтвердите списание звезд

5. **Ожидайте результат:**
   - Парсинг занимает 5-15 минут
   - Бот пришлет уведомление когда все будет готово
   - Вы получите ссылки на все собранные рилсы

## 🔒 Кто может пользоваться?

Доступ есть у:
- Главного администратора (ID: 144022504)
- Сотрудников HaimGroupMedia_bot (ограниченный доступ)
- Сотрудников MetaMuse_Manifest_bot (полный доступ)
- Администраторов из ADMIN_IDS

## ⚠️ Важные ограничения:

1. **Аккаунты должны быть открытыми** - приватные аккаунты парсить нельзя
2. **Используйте только латиницу** - в username и хештегах
3. **Результат зависит от доступности** - Instagram может ограничивать доступ к контенту
4. **Парсинг занимает время** - это не мгновенный процесс

## 📊 Дополнительные функции:

- **📊 Моя статистика** - посмотреть историю парсингов и потраченные звезды
- **❓ Помощь** - подробная справка прямо в боте

## 💡 Что делать с результатами?

После парсинга вы получите:
- Прямые ссылки на рилсы
- Информацию об аккаунтах
- Статистику просмотров и лайков

Эти данные можно использовать для:
- Анализа контента конкурентов
- Поиска трендовых идей
- Исследования популярных тем
- Создания собственного контента

## ❌ Если что-то не работает:

1. Проверьте баланс звезд (нужны звезды для оплаты)
2. Убедитесь, что аккаунт открытый
3. Проверьте правильность написания username/хештега
4. Обратитесь в техподдержку через бота
