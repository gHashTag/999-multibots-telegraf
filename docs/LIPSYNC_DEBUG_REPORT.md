## 🎯 Архитектура LipSync системы

### Поток выполнения:
1. **UI:** `lipSyncWizard` → сбор видео и аудио от пользователя
2. **Валидация:** проверка размера файлов (макс. 50MB)
3. **Платежи:** списание 84.38⭐ с баланса пользователя
4. **Процессинг:** `generateLipSync` → `generateKlingLipSync` → Replicate API
5. **Сохранение:** результат в Supabase через `saveVideoUrlToSupabase`
6. **Ответ:** отправка готового видео пользователю

### Провайдеры:
- **Replicate (Kling)** - основной, быстрый, экономичный
- **Sync Labs** - премиум качество, более дорогой

### Конфигурация моделей:

## 🚀 Инструкции для запуска

### 1. Настройка окружения:
```bash
# Скопировать и заполнить переменные
cp .env.example .env
nano .env
```

### 2. Получить необходимые токены:
- **Replicate:** https://replicate.com/account/api-tokens
- **Supabase:** настройки проекта → API → Project URL & anon key
- **Telegram Bot:** @BotFather → /newbot

### 3. Тестирование:
```bash
# Проверить API подключения
node scripts/test-api-connections.js

# Полная диагностика
node scripts/test-lipsync-diagnosis.js

# Запуск бота
npm start
```

### 4. Проверка в Telegram:
1. Найти команду LipSync в меню бота
2. Отправить видео с лицом (до 50MB)
3. Отправить аудио файл (до 50MB) 
4. Дождаться результата
