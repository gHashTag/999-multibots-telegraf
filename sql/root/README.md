# 🗄️ SQL Скрипты из Корня

Эта папка содержит SQL скрипты, которые были перемещены из корня проекта.

## 📂 Содержимое

- **Миграции** - скрипты для изменения структуры БД
- **Аналитические запросы** - запросы для анализа данных
- **Очистка данных** - скрипты для очистки тестовых данных
- **Резервные копии** - скрипты для бэкапов

## ⚠️ Важно

Основные SQL скрипты проекта находятся в:
- `sql/` - основные SQL файлы
- `sql-scripts/` - дополнительные скрипты
- `migrations/` - миграции базы данных

## 🔍 Использование

Перед выполнением SQL скриптов:
1. Проверьте, что вы работаете с правильной базой данных
2. Сделайте резервную копию перед выполнением деструктивных операций
3. Проверьте зависимости и порядок выполнения
