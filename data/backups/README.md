# 💾 Резервные Копии Данных

Эта папка содержит JSON файлы с резервными копиями данных, которые были перемещены из корня проекта.

## 📂 Содержимое

- **JSON бэкапы** (`.json`) - резервные копии данных из базы
- **Экспортированные данные** - данные, экспортированные для анализа

## 🔍 Типы данных

- Резервные копии платежей
- Экспортированные данные пользователей
- Данные транзакций
- Конфигурационные данные

## ⚠️ Важно

Эти файлы могут содержать чувствительные данные. Не коммитьте их в Git без необходимости.

## 🔄 Восстановление

Для восстановления данных из бэкапа используйте соответствующие скрипты в `scripts/` или `scripts/root/`.
