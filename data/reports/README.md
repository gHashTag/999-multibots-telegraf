# 📊 Отчёты и Данные

Эта папка содержит Excel и CSV файлы с отчётами, которые были перемещены из корня проекта.

## 📂 Содержимое

- **Excel отчёты** (`.xlsx`) - финансовые отчёты, анализы, дашборды
- **CSV файлы** (`.csv`) - экспортированные данные, транзакции

## 📈 Типы отчётов

- Финансовые отчёты по ботам
- Анализы платежей и транзакций
- Отчёты по пользователям
- Дашборды и сводки

## 🔍 Поиск

Для поиска конкретного отчёта:
```bash
find data/reports -name "*KEYWORD*"
```

## ⚠️ Важно

Эти файлы обычно генерируются скриптами. Исходные данные хранятся в базе данных Supabase.
