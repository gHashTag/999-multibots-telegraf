5. Полный прогон рендера и мутации перед слиянием; GitHub Actions стоят

6. Окружение: корневой vitest 5 и `react` в корне (`npm install --no-save

7. Не мутировать файлы, пока идёт полный прогон (он читает их же).
   И сам `bin/tri` тоже (виток 7: правка справки посреди `tri full-run` —
   «unexpected EOF» после прогона). С витка 7 tri — одна группа `{ … };
exit "$?"` и читается целиком до запуска; `exit` на ТОЙ ЖЕ строке, иначе
   bash дочитывает правленый файл после группы (проверено на копии).
   Перед слиянием изменений плеера — `tri image-gate` (виток 8): сборка
   образа плеера гоняет tsc + scripts/test-gate.mjs, и красный тест основы

   полный прогон, не подмножество.
   Код выхода конвейера — код последнего звена: `tri full-run | tail`
   вернул 0 при RED. Вердикт — строка `== render: green/RED`, или без трубы.
   `pkill -f "<команда>"` убивает и свою оболочку, если образец есть в её
   строке — искать pid через `ps | grep [x]`.
