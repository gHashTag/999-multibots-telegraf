# Правила деплоя на production

## ❌ НИКОГДА НЕ ДЕПЛОИТЬ БЕЗ КОМАНДЫ!

**ПРАВИЛО #1:** Деплоить можно ТОЛЬКО если пользователь явно сказал "деплой" или "задеплой" или использовал команду `/deploy`.

**ПРАВИЛО #2:** ВСЕГДА тестировать локально перед деплоем.

**ПРАВИЛО #3:** НЕ делать автоматический деплой после коммита.

## ✅ Правильная последовательность:

1. **Изменить код локально**
2. **Протестировать локально** (`bun --watch src/index.ts`)
3. **Закоммитить изменения** (`git commit`)
4. **Запушить в git** (`git push`)
5. **Дождаться явной команды пользователя на деплой**
6. **Деплой только после подтверждения**

## 🚫 Неправильные действия:

```typescript
// ❌ НЕПРАВИЛЬНО: Автоматический деплой после коммита
git commit && git push && scp ... && ssh prod999 ...

// ❌ НЕПРАВИЛЬНО: Деплой без тестирования локально
// (пропускаем этап локального тестирования)

// ❌ НЕПРАВИЛЬНО: Деплой без подтверждения
// Пользователь: "Исправь кнопку"
// Ассистент: git commit && deploy  // ❌ НЕТ!
```

## ✅ Правильные действия:

```typescript
// ✅ ПРАВИЛЬНО: Полная последовательность с подтверждением
// 1. Локальные изменения
Edit(...)

// 2. Локальное тестирование
User: "Протестируй локально"
// Тестирование через bun --watch

// 3. Коммит после успешного теста
git commit ...

// 4. Дождаться явной команды
User: "Деплой" или "/deploy"
// ТОЛЬКО ТОГДА: scp ... && ssh prod999 ...
```

## Фразы пользователя для деплоя:

- ✅ "деплой"
- ✅ "задеплой"
- ✅ "deploy"
- ✅ "/deploy"
- ✅ "залей на production"
- ✅ "обнови production"

## Фразы, которые НЕ означают деплой:

- ❌ "исправь"
- ❌ "сделай"
- ❌ "добавь"
- ❌ "измени"
- ❌ "протестируй"
- ❌ "проверь"

## Пример правильного диалога:

```
User: Исправь кнопку в ImageToVideo wizard
Assistant: [Исправляет код]
Assistant: [Коммитит изменения]
Assistant: ✅ Исправления закоммичены. Хочешь задеплоить?

User: Нет, сначала протестируй локально
Assistant: [Тестирует локально]
Assistant: ✅ Протестировано локально, работает

User: Деплой
Assistant: [Деплоит на production]
```

## Пример неправильного диалога:

```
User: Исправь кнопку в ImageToVideo wizard
Assistant: [Исправляет код]
Assistant: [Коммитит изменения]
Assistant: [АВТОМАТИЧЕСКИ деплоит]  // ❌ НЕПРАВИЛЬНО!
```

## Исключения:

Деплой БЕЗ явной команды разрешён ТОЛЬКО если:
1. Пользователь в самом начале задачи сказал "исправь и задеплой"
2. Пользователь в процессе работы явно сказал "как исправишь - сразу деплой"
3. Используется команда `/deploy` через SlashCommand tool
