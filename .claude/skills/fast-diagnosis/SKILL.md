# Быстрая диагностика: симптом → команда → смысл ответа

## Правило

**Сначала измерить, потом чинить.** Половина находок этого проекта — починка
того, что не ломалось, и слепота к тому, что сломано. Каждая строка ниже
появилась после случая, когда её отсутствие стоило времени или денег.

**И второе:** у каждого ответа есть третье значение. Не только «да» и «нет», но
и **«я не смог посмотреть»**. Инструмент, который на сломанном чтении отвечает
«чисто», хуже отсутствующего.

---

## Карта: где вообще искать

| вопрос                             | команда                                                                       |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| какие команды вообще есть          | `tri map` (читает сам `tri`), `tri map --undocumented`, `tri map <подстрока>` |
| отвечает ли репозиторий на это уже | `tri already <слова>` — **спрашивать ДО того, как строить**                   |
| что известно про деньги            | `tri money-invariants` — карта, которая называет свои слабые места            |
| полный реестр денежных ратчетов    | `docs/money-ratchets.md` (генерируется)                                       |

> Сначала `tri already`. Дважды за неделю я строил заново то, что уже лежало в
> дереве: `tri mutate` и разбор ответа Робокассы.

## Деньги

| симптом                                             | команда                                                                    | что означает ответ                                                                                                                                       |
| --------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «клиент заплатил и ничего не получил»               | `tri reconcile`                                                            | спрашивает **Робокассу**, а не нашу таблицу. `PAID` при нашем `PENDING` = долг перед человеком                                                           |
| то же, но крипта                                    | `tri ton-pending`                                                          | спрашивает **блокчейн**. «старше окна» ≠ «не платил»                                                                                                     |
| где вообще застревают оплаты                        | `tri stuck`                                                                | по каналам; канал с `lastOK=NEVER` никогда никого не зачислил                                                                                            |
| всё странное разом                                  | `railway run -s 999-multibots-telegraf node scripts/payment-anomalies.cjs` | зависшие, отрицательные балансы, кредиты без ключа, дубли ключей, призрачные плательщики                                                                 |
| нарушены ли инварианты леджера                      | `railway run -s 999-multibots-telegraf node scripts/ledger-integrity.cjs`  | «healed» = историческое, «в окне 0» = сейчас чисто                                                                                                       |
| выбрасывается ли где-то результат денежной операции | `tri money`                                                                | **0 живых** — норма. Словарь: `updateUserBalance`, `directPaymentProcessor`, `processBalanceOperation`, `updatePaymentStatus`, `createSuccessfulPayment` |
| может ли человек вообще заплатить                   | `tri pay`, `tri methods`                                                   | метод, который «можно предложить», обязан уметь **зачислить**                                                                                            |
| живы ли сторожа денег                               | `tri watches`                                                              | «ни разу не отчитывался» ≠ «умер»: смотри на возраст функции                                                                                             |

**Чинить деньги — только так:** возврат это **перевод строки** `PENDING →
COMPLETED` (баланс — сумма `COMPLETED`), сверка суммы — по **независимой**
величине провайдера (`IncSum`), дата — из `StateDate`, сухой прогон по
умолчанию, повторный прогон обязан зачислить **ноль**.

## Боты

| симптом                           | команда                                  | что означает                                                                                                                                                               |
| --------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «главная кнопка не работает»      | `getChatMenuButton` по каждому токену    | `commands` = кнопка открывает список команд, а не приложение. Ставится `setChatMenuButton`; после записи **перечитывать через минуту** — Telegram согласуется не мгновенно |
| бот молчит / не отвечает          | `railway logs` на сервисе бота           | ищи `409 Conflict` (перекрытие деплоев) и `launchWithConflictRetry`                                                                                                        |
| что бот может отдать прямо сейчас | `tri can-deliver`                        | ключи провайдеров, а не только `BOT_TOKEN`                                                                                                                                 |
| человек не получает сообщение     | отправить и **прочитать ответ Telegram** | `chat not found` = никогда не начинал этого бота; `bot was blocked` = заблокировал. Поле `payments_v2.bot_name` — это **касса**, а бот человека — `users.bot_name`         |

## Кроны и функции

| симптом                       | команда                                                                | что означает                                                                           |
| ----------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| тикает ли обход продавца      | `tri clock`                                                            | тишина до 6 часов законна: `sweep-held` пишется раз в heartbeat                        |
| работает ли функция Inngest   | `railway logs` + grep по `fnId=telegram-bot-client-<id>`               | приход `POST /api/inngest?fnId=…` = крон тикнул, регистрация в порядке                 |
| зарегистрированы ли функции   | `curl -X PUT <бот>/api/inngest`                                        | `{"message":"Successfully registered","modified":false}` = сервер уже знает этот набор |
| сколько функций обслуживается | `src/inngest_app/functions.manifest.json` + тест `inngestProbeCommand` | число литералом: новая функция стоит одной минуты размышления                          |

## Деплой и платформа

| симптом                      | команда             | что означает                                                                                           |
| ---------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------ |
| «правка не доехала до прода» | `tri deploy-config` | Railway разрешает путь конфига **от корня репозитория**, а не от Root Directory                        |
| сколько процессов в проде    | `tri replicas`      | все денежные охраны — по-процессные; `multiRegionConfig` складывается                                  |
| куда тянет ветка             | `tri upstream`      | `main`, тянущая чужую ветку, молча вливает чужое                                                       |
| кончилось место              | `tri disk`          | рабочие деревья в scratchpad по ~300 МБ; удалять только чистые и без открытых PR                       |
| **машина не может форкнуть** | `ps -A \| wc -l`    | тысячи `<defunct>` = зомби съели слоты PID. Лечится перезапуском **приложения-родителя**, не терминала |

## Как этот скил обновляется

**Правило: новый опыт дописывается в тот же цикл, когда он получен.** Не «потом
оформлю» — через цикл он выглядит очевидным и не записывается вовсе.

Куда что идёт:

- **симптом → команда** → в таблицы выше;
- **почему сторож не сработал** → в `blind-guards` как очередная форма;
- **число, которое надо помнить** → не сюда, а в тест или в генерируемый файл
  (`docs/money-ratchets.md`, `tri map`), иначе разойдётся;
- **новая команда `tri`** → комментарий в самой команде, и она появится в
  `tri map` **сама**: карта читается из `tri`, второго списка нет.

Признак, что строку пора добавить: **ты потратил больше десяти минут на
вопрос, который уже задавали.** Если ответ нашёлся командой — строка в таблицу.
Если команды не было — сначала `tri already`, и только потом новая команда.

Признак, что строку пора **удалить**: она говорит о том, чего больше нет.
Устаревшая строка прикроет следующую ошибку (та же болезнь, что у переписей:
запись, пережившая свою причину).
