# Оснастка автономного цикла

Инструменты, которыми цикл проверяет САМ СЕБЯ. Все написаны после того, как
очередная ошибка прошла мимо сборки и типов и была поймана только на живом
проде.

| Команда | Что ловит | Чем оплачена |
| --- | --- | --- |
| `node anomalies.mjs` | шаг 0 любой итерации: провайдеры, свежесть ленты, мини-апп, маршруты, профиль, следы правок | ошибки, которых не видно ни в сборке, ни в типах |
| `node add-trace.mjs <pr> <файл> <игла> <заметка>` | записывает след правки, **проверив иглу в `origin/main` прямо сейчас** | три ложные тревоги «правка пропала» подряд — врала игла, записанная по памяти |
| `node verify-landed.mjs` | перезаписал ли новый цикл прошлую работу | сама причина существования этой папки |
| `bash guard.sh acquire\|release` | два агента в одном репозитории | параллельный цикл коммитил поверх |
| `node render-fingerprint.mjs` | вёрстка рилса разъехалась | «опять у тебя рилс кривой вёрсткой» |

## Правило, оплаченное дороже всех

**Зелёная сборка не доказывает ничего. Проверяй на живом деплое.**

Каждый настоящий дефект здесь проходил `npm run build`. Каждый ловился
загрузкой развёрнутой страницы и замером.

## Второе правило

**Тест, который проходит и ДО правки, ничего не доказывает.** Снеси свою же
строку и убедись, что проверка краснеет. Так же и с тревогами: заглушив
сигнал, проверь на копии, что он ещё умеет звучать.

## Чего здесь нет

`STATE.json`, `anomalies-last.json`, `dashboard.html` — состояние прогона.
Оно машинно-локальное и намеренно в `.gitignore`.
