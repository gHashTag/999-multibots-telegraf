`billing-shared.ts` считает `цена = ceil(себестоимость / 0.005)`. Меняешь модель —
**обязан менять `OPERATION_COST_USD`**. Липсинк едва не остался с ценой 18 токенов
от `veed/fabric-1` при переходе на InfiniTalk со стоимостью 3.

## Открыто

### 1. Приложение не умеет опрашивать задачи
Сервер заводит задачу и для липсинка (#1831), маршрут `GET /api/generate/jobs/<id>`
работает. **Клиент по-прежнему ждёт синхронного ответа** — при обрыве теряет
оплаченный результат. Дыра закрыта наполовину.

### 2. Вкладки результата сценария — написаны, не влиты
Ветка `feat/script-output-tabs-v2`, **собирается** (`BUILD SUCCEEDED`).
В вебе есть `script-output-tabs`: Озвучка · Обложка · B-Roll. В приложении
части склеены в одну строку. Осталось снять скриншот и влить.

Проверить, не стал ли выбор поиском.

## Симулятор

`simctl` иногда виснет целиком. Лечится:
```bash
killall -9 com.apple.CoreSimulator.CoreSimulatorService Simulator
```
Затем `boot` и опрос `simctl list devices | grep Booted` — **не** `bootstatus`,
он ждёт бесконечно.
