## Открытое — по убыванию веса

### 1. Предпросмотр пуст на композиции без видео — ДИАГНОЗ ЕСТЬ

`PreviewView.body` показывает `PreviewCanvas` ВСЕГДА (PreviewView.swift:133), то есть
дело не в ветвлении на уровне вьюхи. Пустота идёт ниже: накладка со слоями вешается
на слой `AVPlayer`, а без видеодорожки плеера нет — вешать некуда, и дерево слоёв,
которое `LayerBuilder` честно построил, никуда не попадает.

Следствие: **текстовый ролик нельзя увидеть до экспорта.** При этом экспорт на такой
композиции тоже отказывает (`AVAssetExportSession` собирает из видеодорожек) — то есть
текст без фона в приложении не доводится до результата вообще.

Куда смотреть: `PreviewCanvas` (PreviewView.swift:334+), `PreviewHostView` (:844),
`PreviewOverlay` (:713).

Проверка после правки: редактор с одним текстовым слоем → на холсте видна подпись.

## Правила, чтобы циклы не ломали друг друга

1. `git -C ~/.vibee-worktrees/opus pull --rebase` до любой правки.
2. Один пункт за итерацию, до конца: правка → сборка → скриншот → PR → обновить этот
   файл и `dashboard-opus.html`.
3. Замер вместо догадки: значения веба снимать `getComputedStyle`, не с картинки.
4. Диск: `df -h` до сборки. Чистить только регенерируемое (DerivedData, кэши, npm).
   `~/Movies` и `~/Library/Containers` — файлы пользователя, НЕ трогать.
5. Сообщения коммитов по-английски, разговор с пользователем по-русски.
