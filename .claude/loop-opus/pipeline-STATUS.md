## Второе правило: цена выводится из себестоимости

`billing-shared.ts` считает `цена = ceil(себестоимость / 0.005)`. Меняешь модель —
**обязан менять `OPERATION_COST_USD`**. Липсинк едва не остался с ценой 18 токенов
от `veed/fabric-1` при переходе на InfiniTalk со стоимостью 3.

## Открыто — по убыванию веса

### 1. Прокси врёт типом
`/proxy/image` на `.svg`-аватарку Telegram отдаёт **42-байтный 1×1 GIF** с
`Content-Type: image/jpeg`. Липсинк по аватарке молча не работает: файл есть,
тип объявлен, содержимого нет. Либо растрировать SVG, либо честно отказать.

### 2. Обложек нет у всех 20 ассетов
`thumbnailUrl` пуст у каждого — в профиле чёрные карточки. Найти, почему рендер
публикуется без обложки.

### 3. Звук через KIE
`elevenlabs/text-to-speech-multilingual-v2` отвечает `Internal Error`. Работает
запасной путь (replicate). В каталоге есть другие модели звука — переключить
разрешённую, **как сделали с липсинком**, не забыв цену.

### 4. Админ и общий счёт
Биллинга для админов **нет**: `ensureRow` даёт всем 20 токенов. Пользователь
ожидает общий счёт как админ. Нужен признак админа и источник средств —
**спросить, не делать вслепую**.
