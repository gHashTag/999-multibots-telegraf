Цена принятых решений

Клипы теперь одного цвета на все типы дорожек — как в вебе. Тип дорожки больше не читается по заливке; он подписан слева в заголовке, но информации на экране стало меньше. Это плата за совпадение с вебом, и она обратима.

Правила цикла

Каждая итерация: git pull --rebase → один пункт → сборка → скриншот → самокритика и поиск аномалии → PR → обновление этого дашборда. Новый запуск не трогает сделанное прошлым: список открытого ведётся здесь и в pipeline-STATUS.md. Диск проверяется до сборки; чистится только регенерируемое — файлы пользователя не трогаются.
