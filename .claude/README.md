# 🎉 Автоматическая система очистки PR

Система автоматических хуков для Claude Code, которая обеспечивает чистые Pull Request без вспомогательных файлов.

## 🔄 Автоматический Git Flow

### 1️⃣ В НАЧАЛЕ задачи (UserPromptSubmit):
- ✅ Автоматически создается PR для текущей ветки
- ✅ Ветка автоматически пушится в origin  
- ✅ Умный заголовок PR на основе названия ветки
- ✅ Сохраняется ссылка на PR для отслеживания

### 2️⃣ В ПРОЦЕССЕ работы (PreToolUse):
- ✅ Автоматическая очистка от вспомогательных файлов
- ✅ Очистка избыточной документации
- ✅ Удаление временных скриптов и данных

### 3️⃣ В КОНЦЕ задачи (Stop):
- ✅ Полный отчет с информацией о PR
- ✅ Статус PR (готов к слиянию, ревью, конфликты)
- ✅ Рекомендации по дальнейшим действиям

## 📁 Структура системы

```
.claude/
├── hooks.json                    # Конфигурация всех хуков
├── settings.json                 # Настройки Claude Code (существующие)
├── README.md                     # Эта документация
└── hooks/
    ├── auto-pr-start.sh         # Автосоздание PR в начале задачи
    ├── pr-status.sh             # Отчет о PR в конце задачи  
    ├── pr-cleanup.sh            # Очистка от мусора
    └── docs-cleanup.sh          # Очистка документации
```

## 💻 Ручное управление

```bash
# Создать PR вручную
./.claude/hooks/auto-pr-start.sh

# Показать отчет о PR
./.claude/hooks/pr-status.sh

# Запустить очистку
./.claude/hooks/pr-cleanup.sh

# Очистить документацию
./.claude/hooks/docs-cleanup.sh
```

## ⚙️ Настройка GitHub CLI

Для работы автоматического создания PR необходимо настроить GitHub CLI:

```bash
# Установка GitHub CLI (если не установлен)
brew install gh

# Авторизация
gh auth login

# Проверка статуса
gh auth status
```

## 🛡️ Безопасность

Система автоматически:
- Удаляет конфиденциальные файлы перед коммитом
- Проверяет .gitignore на актуальность  
- Предотвращает утечку секретов в PR
- Очищает временные данные пользователей

## 🔧 Интеграция с существующими хуками

Система совместима с существующими хуками в `settings.json` и дополняет их функциональность для Git Flow.

## 🎯 Результат

**Больше никаких потерянных задач!**
- PR создается автоматически при начале любой задачи
- В конце всегда получаете ссылку на PR
- Полный контроль над множественными параллельными задачами  
- Чистые PR без мусора благодаря автоочистке

## 🚀 Как это работает

1. **Начинаете новую задачу** → автоматически создается PR
2. **Работаете в Claude Code** → система автоматически очищает мусор
3. **Завершаете задачу** → получаете полный отчет о PR
4. **Переходите к ревью** → PR уже готов, чистый и организованный

**Все происходит автоматически, вы просто работаете как обычно!**
