## 📦 DEPLOY СКРИПТ

### Использование:
```bash
./deploy.sh [команда]
```

### Доступные команды:

#### 1. **deploy** - Полный деплой
```bash
./deploy.sh deploy
```
**Что делает:**
- Обновляет код с git (production ветка)
- Пересобирает Docker образ
- Останавливает старый контейнер
- Запускает новый контейнер
- Проверяет статус
- Создаёт снапшот для отката

#### 2. **status** - Проверка статуса
```bash
./deploy.sh status
```
**Показывает:**
- Статус всех контейнеров
- Количество инициализированных ботов
- API health check
- Последние логи

#### 3. **logs** - Просмотр логов
```bash
./deploy.sh logs 100      # Последние 100 строк
./deploy.sh logs 50       # Последние 50 строк (follow mode)
```

#### 4. **list** - Список снапшотов
```bash
./deploy.sh list
```
Показывает все доступные снапшоты с размерами.

#### 5. **help** - Справка
```bash
./deploy.sh help
```

## 💾 СНАПШОТЫ DOCKER

### Автоматические снапшоты
При каждом деплое автоматически создаётся снапшот:
```
/root/docker-snapshot-prod-stable-20251031_151934.tar.gz
```

### Формат имени:
```
prod-stable-YYYYMMDD_HHMMSS.tar.gz
```

### Ручное создание снапшота:
```bash
# На сервере
docker save 999-agents-telegraf:latest | gzip > /root/my-snapshot.tar.gz
```

### Загрузка снапшота:
```bash
# На сервере
docker load < /root/docker-snapshot-prod-stable-20251031_151934.tar.gz
```

## ⚠️ ВАЖНЫЕ ЗАМЕТКИ

1. **Снапшоты сохраняются на сервере** в `/root/docker-snapshot-*.tar.gz`
2. **Каждый деплог создаёт новый снапшот** для возможности отката
3. **Все команды автоматизированы** - не нужно вручную пересобирать
4. **Rollback занимает ~1 минуту** (остановка + загрузка + запуск)
5. **Deploy занимает ~3 минуты** (git + build + restart)
