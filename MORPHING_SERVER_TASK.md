# 🧬 ТЗ: Реализация эндпоинта морфинга изображений

## 📋 Общее описание

Необходимо создать серверный эндпоинт для обработки морфинга изображений с использованием модели Kling-v1.6. Эндпоинт должен принимать ZIP архив с изображениями и возвращать видео с плавными переходами между кадрами.

## 🎯 Основная задача

Создать API эндпоинт `/generate/morph-images` для создания морфинг-видео из последовательности изображений.

---

## 📡 Технические требования

### 🔗 Маршрут
```
POST /generate/morph-images
```

### 🔑 Аутентификация
```javascript
headers: {
  'x-secret-key': SECRET_API_KEY,
  'Content-Type': 'multipart/form-data'
}
```

### 📥 Входные данные (FormData)

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `type` | string | ✅ | Всегда `"morphing"` |
| `telegram_id` | string | ✅ | ID пользователя Telegram |
| `images_zip` | File | ✅ | ZIP архив с изображениями |
| `image_count` | string | ✅ | Количество изображений в архиве |
| `morphing_type` | string | ✅ | `"seamless"` или `"loop"` |
| `model` | string | ✅ | `"kling-v1.6-pro"` |
| `is_ru` | string | ✅ | `"true"` или `"false"` |
| `bot_name` | string | ✅ | Имя бота для логирования |

### 📤 Выходные данные (JSON)

**При успехе:**
```json
{
  "message": "Морфинг отправлен на обработку",
  "job_id": "uuid-string",
  "status": "processing",
  "estimated_time": "5-10 минут"
}
```

**При ошибке:**
```json
{
  "message": "Ошибка обработки морфинга",
  "error": "Описание ошибки",
  "status": "error"
}
```

## 🔄 Алгоритм обработки

### 1. 🛡️ Валидация входных данных
- [ ] Проверить `x-secret-key` в заголовках
- [ ] Валидировать наличие всех обязательных полей
- [ ] Проверить, что `images_zip` - валидный ZIP файл
- [ ] Убедиться, что `image_count` >= 2 и <= 100

### 2. 📁 Обработка ZIP архива
- [ ] Создать временную папку для данного `telegram_id`
- [ ] Распаковать ZIP архив во временную папку
- [ ] Отсортировать изображения по именам файлов (`morphing_frame_1.jpg`, `morphing_frame_2.jpg`, ...)
- [ ] Валидировать, что все файлы - корректные изображения

### 3. 🧬 Создание морфинга

- [ ] Настроить параметры морфинга:

  - **loop**: замкнутый цикл (последний кадр переходит в первый)
- [ ] Отправить запрос к Kling-v1.6 API
- [ ] Получить job_id или ссылку на результат

### 4. 💾 Сохранение результата

- [ ] Получить публичную ссылку на видео

### 5. 📱 Уведомление пользователя

## 🔧 Интеграции

### 🤖 Kling-v1.6 API
```javascript
// Примерная структура запроса к Kling
{
  "model": "kling-v1.6-pro",
  "task_type": "image_morphing",
  "images": [
    "base64_image_1",
    "base64_image_2",
    "base64_image_3"
  ],
  "transition_type": "seamless", // или "loop"
  "output_format": "mp4",
  "quality": "high"
}
```

### 💾 Хранилище файлов
- **S3** или **Pinata** для загрузки готового видео
- Получение публичной ссылки для передачи пользователю

### 📊 База данных (Supabase)
```sql
-- Примерная структура записи
INSERT INTO morphing_jobs (

  image_count,
  morphing_type,
  status,
  video_url,
  created_at,
  completed_at
) VALUES (?, ?, ?, ?, ?, ?, NOW(), ?)
```

// Отправка готового видео пользователю
await sendVideo(telegram_id, video_url, {
