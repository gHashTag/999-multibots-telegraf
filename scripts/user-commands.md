# 🤖 Документация команд Telegram User Access Agent

## Обзор

Специализированный агент для автоматизации управления пользователями Telegram-ботов с функциями:
- Автоматическое обнаружение Telegram ID в сообщениях
- Анализ статуса пользователей (база, баланс, подписки)
- Генерация автоматических рекомендаций
- Выполнение действий по управлению пользователями
- Создание готовых SSH команд

## 🚀 Установка и настройка

```bash
# Сделать файл исполняемым
chmod +x /Users/playra/999-agents-telegraf/scripts/user-access-agent.js

# Создать символическую ссылку для глобального доступа (опционально)
sudo ln -s /Users/playra/999-agents-telegraf/scripts/user-access-agent.js /usr/local/bin/telegram-agent
```

## 📋 Основные команды

### 1. Анализ сообщений с автоматическим обнаружением Telegram ID

### 2. Выполнение действий

```bash
# Предоставить NEUROTESTER подписку
node user-access-agent.js action 123456789 grant_neurotester

# Проверить доступ к функциям
node user-access-agent.js action 123456789 check_access

# Создать пользователя в БД
node user-access-agent.js action 123456789 create_user

# Сгенерировать детальный отчет
node user-access-agent.js action 123456789 generate_report

# Проверить статус подписки
node user-access-agent.js action 123456789 check_subscription
```

### 3. Генерация отчетов

```bash
# Детальный отчет по пользователю
node user-access-agent.js report 123456789
```

## 🔧 Доступные действия

| Действие | Описание | Использование |
|----------|----------|---------------|
| `grant_neurotester` | Предоставляет безлимитную NEUROTESTER подписку | Для пользователей с высоким балансом |
| `check_access` | Проверяет доступ ко всем функциям бота | Диагностика проблем пользователя |
| `create_user` | Создает запись пользователя в БД | Для новых пользователей |
| `generate_report` | Создает детальный отчет о пользователе | Анализ и документирование |
| `check_subscription` | Проверяет статус активных подписок | Диагностика подписок |

## 🎯 Автоматические рекомендации

Агент автоматически анализирует статус пользователя и генерирует рекомендации:

### Сценарий 1: Высокий баланс + нет подписки
```
Условие: Баланс ≥ 1000 XTR && нет активной подписки
Рекомендация: Предоставить NEUROTESTER подписку
Действие: grant_neurotester
```

### Сценарий 2: Пользователь не найден
```
Условие: isExist = false
Рекомендация: Создать запись в БД
Действие: create_user
```

### Сценарий 3: Истекшая подписка
```
Условие: subscriptionType != null && isSubscriptionActive = false
Рекомендация: Обновить до NEUROTESTER подписки
Действие: grant_neurotester
```

### Сценарий 4: Низкий баланс
```
Условие: Баланс < 100 XTR
Рекомендация: Уведомить о пополнении баланса
Действие: notify_low_balance
```

## 🗄️ Структура данных

### Типы подписок
- `NEUROTESTER` - Безлимитная подписка (рекомендуется)
- `NEUROVIDEO` - Подписка на видео
- `NEUROPHOTO` - Подписка на фото
- `STARS` - Базовая подписка

### Пороговые значения
- Высокий баланс: ≥ 1000 XTR
- Низкий баланс: < 100 XTR
- Неактивная подписка: > 30 дней

## 📊 Интеграция с Claude

### Автоматический триггер
Агент автоматически активируется при обнаружении в сообщении паттерна Telegram ID:
- Regex: `\d{8,12}`
- Минимальная длина: 8 цифр
- Максимальная длина: 12 цифр

### Примеры сообщений-триггеров
```
"Пользователь 123456789 не может использовать нейрофото"
"ID: 987654321 - проблемы с подпиской"
"Жалоба от 555666777 на медленную работу"
"Баланс у 444333222 показывает 0"
```

## 🔄 Workflow использования

### 1. Автоматический режим (рекомендуется)
```
Пользователь упоминает Telegram ID → 
Агент автоматически анализирует → 
Выводит рекомендации и SSH команды → 
Пользователь выбирает действие для выполнения
```

### 2. Ручной режим
```bash
# Шаг 1: Анализ
node user-access-agent.js analyze "ID пользователя"

# Шаг 2: Выполнение рекомендованного действия
node user-access-agent.js action TELEGRAM_ID ACTION_NAME

# Шаг 3: Проверка результата
node user-access-agent.js report TELEGRAM_ID
```
