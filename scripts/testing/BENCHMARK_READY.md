## 🚀 **КАК ЗАПУСТИТЬ БЕНЧМАРК:**

### Шаг 1: Подготовка 📋
```bash
# Запустить план бенчмарка
node scripts/testing/flux-camera-benchmark.js

# Получить пошаговые инструкции  
node scripts/testing/flux-benchmark-helper.js
```

### Шаг 2: Тестирование 🎬
1. **Загрузить тестовое изображение:** `assets/bible_vibecoder/lyps-sync.jpg`
2. **Перейти в бот:** `/menu` → `🎨 FLUX Kontext` → `🎬 Управление камерой`
3. **Тестировать каждый угол с двумя моделями:**
   - Сначала с Max моделью (текущая)
   - Затем с Pro моделью (изменить в коде)

### Шаг 3: Переключение модели 🔧
В файле `src/scenes/fluxKontextScene/index.ts`, функция `handleCameraSetting`:
```typescript
// Для тестирования Max модели:
ctx.session.kontextModelType = 'max'

// Для тестирования Pro модели:  
ctx.session.kontextModelType = 'pro'
```
