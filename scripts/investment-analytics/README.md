# 📊 Investment Analytics Suite

**Единая система для полного инвестиционного анализа бот-фермы**

---

## 🎯 Описание

Единый тест, который выполняет:
1. ✅ Полный анализ всех инвестиционных метрик
2. 📊 Создание Excel отчета с данными
3. 📝 Генерация итогового отчета в Markdown

---

## 📁 Структура

```
scripts/investment-analytics/
├── full-analytics.test.ts      # Основной тест
└── README.md                   # Этот файл
```

---

## 🚀 Использование

### Запуск полного анализа:

```bash
# Основной запуск
npm test -- investment-analytics/full-analytics.test.ts

# С детальным выводом
npm test -- investment-analytics/full-analytics.test.ts --reporter=verbose

# С покрытием
npm run test:coverage -- investment-analytics/full-analytics.test.ts
```

---

## 📊 Что создает тест

### 1. Excel файл: `INVESTMENT_ANALYSIS_REPORT.xlsx`

**Листы:**
- 📋 **EXECUTIVE SUMMARY** - ключевые метрики
- 🤖 **АНАЛИЗ БОТОВ** - детализация по каждому боту
- 🤖 **AI ПРОВАЙДЕРЫ** - затраты на AI
- 💎 **ВАЛЮТЫ** - диверсификация доходов
- 👥 **ТОП ПОЛЬЗОВАТЕЛИ** - топ-50 пользователей

### 2. Отчет: `INVESTMENT_ANALYSIS_REPORT.md`

**Содержание:**
- Исполнительное резюме
- Анализ ботов (топ-5)
- AI провайдеры (топ-5)
- Диверсификация по валютам
- Топ-10 пользователей
- Ключевые выводы
- Рекомендации
- Прогноз на 12 месяцев

---

## 📈 Метрики которые рассчитывает

### Финансовые:
- ✅ Общие доходы/расходы/прибыль
- ✅ ROI (Return on Investment)
- ✅ Gross Margin
- ✅ Доход на пользователя (ARPU)

### Пользовательские:
- ✅ Количество пользователей
- ✅ Активные пользователи
- ✅ Операции пользователей

### Операционные:
- ✅ Метрики по каждому боту
- ✅ Затраты на AI провайдеров
- ✅ Диверсификация валют

---

## ⏱️ Время выполнения

- **Загрузка данных:** ~30-60 сек
- **Расчет метрик:** ~10-20 сек
- **Создание Excel:** ~5-10 сек
- **Генерация отчета:** ~2-5 сек
- **ИТОГО:** ~1-2 минуты
