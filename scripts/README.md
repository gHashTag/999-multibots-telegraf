# Scripts Directory Structure

This directory contains all project scripts organized by category:

## 📁 Structure

### `sql/` - Database Schema & Migration Scripts
- SQL files for database modifications
- Table creation and alteration scripts
- Translation and bot setup scripts

### `database/` - Data Analysis & Management Scripts  
- User analysis and debugging scripts
- Balance and subscription management
- Cost analysis and anomaly detection scripts
- Mass operations and data fixes

### `testing/` - Test & Verification Scripts
- Integration tests and API tests  
- System verification scripts
- Model availability checks
- Local testing utilities

### `deployment/` - Deployment & Infrastructure Scripts
- Production deployment scripts
- Server management and updates
- Environment setup and configuration
- Service restart and monitoring scripts

### `core/` - Core System Scripts
- Build and integrity checks
- System metrics and monitoring  
- Task management utilities
- MCP integration scripts

### `fix-errors/` - Error Handling & Recovery Scripts  
- Docker and environment fixes
- Token validation and auth fixes
- Git and system repairs

## 🚀 Usage

Each subdirectory contains scripts for specific purposes. Check individual README files in subdirectories for detailed usage instructions.

## 📝 Notes

- Always test scripts in development environment first
- Backup data before running database modification scripts
- Check script dependencies and environment variables
- Some scripts may require specific permissions or tokens
