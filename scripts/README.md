# 🚀 Скрипты развертывания

## Основная команда развертывания

```bash
# Автоматическое развертывание в продакшн
npm run deploy
```

## Доступные скрипты

### [`deploy.sh`](deploy.sh)
🚀 **Автоматическое развертывание в продакшн**
- Коммитит изменения
- Пушит в production branch
- Принудительно пересобирает Docker БЕЗ кеша
- Запускает новый контейнер
- Проверяет результат

**Использование:**
```bash
npm run deploy
# или
./scripts/deploy.sh
```

### Другие скрипты

- `docker-entrypoint.sh` - Точка входа Docker контейнера
- `sync-env.sh` - Синхронизация переменных окружения
- `kill-port.cjs` - Очистка портов для разработки

## 🚨 Важно

**При изменении TypeScript/JavaScript кода ВСЕГДА используйте:**
```bash
npm run deploy
```

**НЕ используйте** `docker restart` - это НЕ применит изменения кода!
