# 🔧 Скрипты из Корня Проекта

Эта папка содержит скрипты (`.js`, `.sh`, `.py`), которые были перемещены из корня проекта для лучшей организации.

## 📂 Содержимое

- **JavaScript скрипты** (`.js`) - утилиты, анализаторы, генераторы отчётов
- **Shell скрипты** (`.sh`) - скрипты для автоматизации
- **Python скрипты** (`.py`) - скрипты для анализа данных

## ⚠️ Важно

Основные скрипты проекта находятся в папке `scripts/` в корне проекта.

Скрипты из корня, которые используются для деплоя и сборки, остались в корне:
- `deploy.sh`, `deploy-*.sh` - скрипты деплоя
- `build-*.sh` - скрипты сборки
- `rollback.sh` - откат изменений
- `dev.js`, `index.js` - точки входа

## 🔍 Использование

Большинство скриптов здесь - это разовые утилиты или скрипты для анализа. Перед использованием проверьте их назначение и зависимости.
