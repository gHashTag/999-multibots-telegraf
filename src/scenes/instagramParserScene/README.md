# Instagram Parser Scene

## Описание
Сцена Instagram парсера с кнопочным интерфейсом для сбора рилсов из Instagram по username аккаунта или хештегу.

## Функционал
- 👤 Парсинг рилсов конкурентов (по username)
- #️⃣ Парсинг рилсов по хештегам
- 📊 Просмотр статистики парсингов
- ❓ Справка по использованию
- 💰 Оплата звездами с проверкой баланса

## Цены
- 10 рилсов = 3 ⭐
- 25 рилсов = 8 ⭐
- 50 рилсов = 15 ⭐
- 100 рилсов = 30 ⭐
- 200 рилсов = 55 ⭐ (скидка)

## Доступ
Доступ к функции парсинга ограничен и настраивается через функцию `getParsingAccess` в `src/menu/mainMenu.ts`:
- Главный админ (ID: 144022504) - полный доступ
- Сотрудники HaimGroupMedia_bot - ограниченный доступ к проектам
- Сотрудники MetaMuse_Manifest_bot - полный доступ
- Админы из ADMIN_IDS - полный доступ

## Интеграция
1. Сцена экспортируется из `src/scenes/instagramParserScene/index.ts`
2. Регистрируется в stage в `src/registerCommands.ts`
3. Добавлен режим `InstagramParserScene` в `src/interfaces/modes.ts`
4. Кнопка появляется в главном меню для пользователей с доступом
5. Обработчик кнопки добавлен в `src/handlers/handleMenu.ts`

## Использование

### Через команду
```
/instagram - запускает Instagram парсер (проверяет доступ)
```

### Через кнопку в меню
Кнопка "📱 Instagram парсер" появляется в главном меню только для пользователей с доступом.

## Технические детали
- Использует Wizard Scene из Telegraf
- Интеграция с Inngest для фоновой обработки
- Списание баланса через `updateUserBalance`
- Статистика сохраняется в таблице `instagram_scrapings`
- Поддержка русского и английского языков

## Процесс парсинга
1. Выбор типа парсинга (конкурент/хештег)
2. Ввод цели (username или hashtag)
3. Выбор количества рилсов
4. Проверка баланса и подтверждение оплаты
5. Запуск парсинга через Inngest
6. Отправка результатов пользователю (5-15 минут)
