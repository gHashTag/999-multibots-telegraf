# 🏦 Currency Rate Module

Модуль для получения актуального курса USDT/RUB через Bybit API. Автоматически кеширует результаты и имеет встроенную обработку ошибок.

## 📥 Установка

1. Скопируйте папку `currency-rate` в ваш проект
2. Убедитесь что у вас установлен модуль для логирования или замените его на свой

## 🚀 Использование

### Простой пример
```typescript
import { getCurrentRate } from '@/modules/currency-rate'

// Получить текущий курс
const rate = await getCurrentRate()
console.log(`Курс USDT/RUB: ${rate}`)
```

### Расширенные опции
```typescript
// Без использования кеша
const freshRate = await getCurrentRate({ cache: false })

// С собственным fallback значением
const rate = await getCurrentRate({ fallback: 90 })

// Очистить кеш если нужно
import { clearRateCache } from '@/modules/currency-rate'
clearRateCache()
```

## ⚙️ Конфигурация

Основные константы в модуле:
- `CACHE_TTL`: 300000 (5 минут) - время жизни кеша
- `DEFAULT_RATE`: 85 - значение по умолчанию при ошибках
- `BYBIT_API_URL`: URL API Bybit для получения курса

## 📝 API

### getCurrentRate(options?)

Получает актуальный курс USDT/RUB.

#### Параметры
- `options.cache` (boolean, по умолчанию: true) - использовать ли кеширование
- `options.fallback` (number, по умолчанию: 85) - значение при ошибке

#### Возвращает
- `Promise<number>` - текущий курс USDT/RUB (округленный до целого числа)

### clearRateCache()

Очищает кеш курса валют.

## 🔄 Как это работает

1. При запросе сначала проверяется кеш (если включен)
2. Если кеш актуален - возвращается значение из кеша
3. Иначе делается запрос к Bybit API
4. Из ответа берется минимальная цена среди всех предложений
5. Результат кешируется (если включено) и возвращается
6. При ошибках возвращается кешированное значение или fallback

## 🛡️ Обработка ошибок

Модуль автоматически обрабатывает:
- Ошибки сети
- Невалидные ответы API
- Пустые или невалидные цены
- Таймауты и другие проблемы

## 📋 Требования

- Node.js с поддержкой fetch API
- TypeScript (опционально)
- Модуль для логирования (или его замена)
