# Тесты для generateImageToVideo

Этот каталог содержит тесты для функции `generateImageToVideo` и связанных вспомогательных функций.

## Структура тестов

- `generateImageToVideo.test.ts` - основные тесты для главной функции
- `generateImageToVideo.helpers.test.ts` - тесты для вспомогательных функций
- `vitest.config.ts` - конфигурация Vitest для локального запуска

## Запуск тестов

### Из корневой директории проекта:
```bash
# Запуск всех тестов
bun run test:vitest

# Запуск только тестов videoGenerator
bun run test:vitest src/modules/videoGenerator/test/

# Запуск с покрытием
bun run test:vitest --coverage src/modules/videoGenerator/test/
```

### Из директории bot-farm:
```bash
cd services/bot-farm

# Запуск всех тестов
bun run test:vitest

# Запуск конкретного файла
bun run test:vitest src/modules/videoGenerator/test/generateImageToVideo.test.ts
```

## Добавление новых тестов

1. Создайте новый файл `*.test.ts` в этой директории
2. Используйте паттерн `describe` -> `it` для группировки тестов
3. Мокайте все внешние зависимости
4. Тестируйте как успешные, так и ошибочные сценарии
5. Проверяйте вызовы функций и возвращаемые значения

## CI/CD

Тесты автоматически запускаются в CI/CD pipeline при каждом PR и пуше в main ветку.
