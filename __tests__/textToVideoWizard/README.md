# TextToVideoWizard Test Suite

Этот каталог содержит полный тест-сьют для TextToVideoWizard, включая сам wizard и все его тесты в одном месте.

## Структура

- `textToVideoWizard.ts` - Копия wizard'а для тестирования
- `textToVideoWizard.test.ts` - Комплексные тесты всех сценариев wizard'а
- `README.md` - Этот файл с документацией

## Запуск тестов

```bash
# Запуск только этих тестов
npm test -- textToVideoWizard

# Запуск с детальным выводом
npm test -- textToVideoWizard --verbose

# Запуск в watch режиме
npm test -- textToVideoWizard --watch
```

## Покрытие тестов

Тесты покрывают следующие сценарии:

### ✅ Создание Wizard'а
- Правильное создание WizardScene с ID 'text_to_video'
- Наличие 3 шагов в wizard'е
- Валидация что все шаги являются функциями

### ✅ Шаг 1: Выбор модели
- Отображение клавиатуры выбора моделей на русском языке
- Отображение клавиатуры выбора моделей на английском языке  
- Обработка отсутствующей конфигурации моделей
- Логирование выполнения шагов
- Обработка ошибок gracefully

### ✅ Шаг 2: Обработка выбора модели
- Правильная обработка различных выборов моделей
- Сохранение параметров в сессии (модель, соотношение сторон, стоимость)
- Обработка кнопки "Назад"
- Обработка повторного клика по кнопке меню
- Обработка неизвестного ввода
- Обработка отсутствующего текстового сообщения

### ✅ Шаг 3: Обработка промпта
- Обработка валидного промпта и запуск генерации видео
- Проверка коротких промптов (валидация длины)
- Обработка пустых промптов
- Использование fallback значений при отсутствии данных сессии
- Обработка отсутствующего текстового сообщения
- Graceful обработка ошибок генерации

### ✅ Обработчики Enter/Leave
- Логирование входа в wizard
- Очистка данных сессии при выходе
- Сохранение других данных сессии

### ✅ Вспомогательные функции
- Расчет стоимости в звездах из конфигурации
- Создание кнопок моделей
- Парсинг выбора модели

### ✅ Edge Cases
- Контекст без user ID
- Контекст без scene
- Очень длинные промпты
- Отсутствующие зависимости

## Моки и заглушки

Тесты используют следующие моки:
- `@/helpers/centralizedLanguage` - определение языка
- `@/handlers/handleTextToVideoDirect` - генерация видео
- `@/services/generateTextToVideo` - сервис генерации
- `@/modules/videoGenerator/config/models.config` - конфигурация моделей
- `@/utils/logger` - логирование

## Отладка тестов

Если тесты падают, проверьте:

1. **Импорты**: Все ли пути импортов корректны
2. **Моки**: Правильно ли замокированы зависимости  
3. **Контекст**: Корректно ли создан mock контекст Telegraf
4. **Сессия**: Правильно ли настроена структура сессии
5. **Async/Await**: Все ли асинхронные операции правильно обработаны

## Результаты

После исправления wizard'а все тесты должны проходить. Если какие-то тесты падают, это указывает на проблемы в логике wizard'а, которые нужно исправить.
