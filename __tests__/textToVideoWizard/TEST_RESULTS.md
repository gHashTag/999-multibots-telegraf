## 🔧 Исправленные Проблемы

### 1. ❌ Проблема: Двойное выполнение первого шага
**Описание:** В `textToVideoWizard.enter()` обработчике выполнялся первый шаг вручную, хотя Telegraf уже автоматически вызывает первый шаг при входе в WizardScene.

**Решение:** 
- Удалил ручное выполнение первого шага из `enter()` обработчика  
- Оставил только логирование в `enter()` обработчике
- Теперь Telegraf корректно обрабатывает первый шаг автоматически

## 🔍 Выявленные и Исправленные Проблемы

### 🚫 Проблема с двойным выполнением
**Было:**
```typescript
textToVideoWizard.enter(async ctx => {
  // ... Ручное выполнение первого шага
  const firstStepHandler = (ctx.wizard as any).steps[0]
  await firstStepHandler(ctx) // ❌ НЕПРАВИЛЬНО
})
```

**Стало:**
```typescript  
textToVideoWizard.enter(async ctx => {
  // Только логирование, без ручного выполнения
  logger.info('[TextToVideoWizard] Wizard entered successfully')
  // Telegraf автоматически вызовет первый шаг ✅
})
```

### ✅ Правильный паттерн WizardScene

Теперь wizard следует правильному паттерну как в `morphingWizard`:

1. **Enter handler** только логирует вход
2. **Первый шаг** выполняется автоматически Telegraf'ом  
3. **Каждый шаг** вызывает `ctx.wizard.next()` для продвижения
4. **Leave handler** очищает данные сессии
