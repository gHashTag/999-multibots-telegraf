# Changelog - Neurophoto Plugin

## [0.2.0] - 2025-01-12 03:00

### 🎭 Major Update: LoRA Support with Fal.ai Integration

**Проблема**: Нужна поддержка персонализированной генерации изображений с пользователем.

**Решение**: Добавлена полная интеграция Fal.ai с LoRA моделями для персонализированной генерации.

### ✨ Что добавлено:

#### 1. **Fal.ai Service**
```typescript
// Новый сервис для fal.ai
class FalService extends Service {
  - Поддержка Flux LoRA моделей
  - Автоматическое добавление триггерного слова
  - Настраиваемый LoRA scale (0.5-1.5)
  - Размер изображения: 768x1365 (9:16)
}
```

#### 2. **LoRA Configuration**
```typescript
// Настройки LoRA
{
  path: 'https://v3b.fal.media/files/.../pytorch_lora_weights.safetensors',
  scale: 1.0,
  triggerWord: 'NEURO_SAGE'
}
```

#### 3. **Dual Provider Support**
```typescript
// Выбор провайдера
IMAGE_PROVIDER=fal       // LoRA поддержка
// или
IMAGE_PROVIDER=replicate // Базовые модели
```

#### 4. **Vertical Format (9:16)**
- Размер по умолчанию: 768x1365
- Идеально для Instagram/TikTok/Stories
- Вертикальная ориентация для соцсетей

#### 5. **Auto Trigger Word**
```
Пользователь: "нарисуй меня на пляже"
↓
Система: "NEURO_SAGE нарисуй меня на пляже"
↓
LoRA активирована!
```

#### 6. **Enhanced Metadata**
```typescript
{
  loraUsed: 'URL к LoRA',
  triggerWord: 'NEURO_SAGE',
  model: 'fal-ai/flux-lora'
}
```

## [0.1.1] - 2025-01-12 02:30

### 🎉 Улучшения распознавания намерений

**Проблема**: Бот не реагировал на естественные запросы, требовал строгие команды.

**Решение**: Добавлен умный анализ намерений пользователя.

### ✨ Что добавлено:

#### 1. **Улучшенный validate()**
```typescript
// Было: Только строгие ключевые слова
'нейрофото', '/neurophoto', 'draw'

// Стало: Понимает естественный язык
✅ "покажи как выглядит..."
✅ "сделай фото..."
✅ "хочу увидеть..."
✅ "can you draw..."
✅ "show me..."
```

#### 2. **Расширенные примеры для LLM**
Добавлено 6 примеров conversations:
- Прямая команда `/neurophoto`
- Естественный запрос "создай изображение..."
- Вопрос "покажи как выглядит..."
- Английские запросы
- Разные формулировки

#### 3. **Улучшенный description**
```typescript
description: `Генерирует AI-изображения с помощью Flux/SDXL моделей.
Используй когда пользователь:
- Просит нарисовать/создать/сгенерировать изображение
- Хочет увидеть как что-то выглядит
- Спрашивает "покажи...", "сделай фото...", "нарисуй..."
- Использует команду /neurophoto
Не требует строгого формата команды - понимает естественный язык.`
```

#### 4. **Красивый вывод модели**
```typescript
// Было:
🤖 Модель: black-forest-labs/flux-schnell

// Стало:
🎨 Модель: Flux Schnell ⚡️
Модель AI: black-forest-labs/flux-schnell
```

Теперь показывает:
- Красивое название с emoji
- Полный ID модели для технических деталей

#### 5. **Документация**

Создано 3 новых файла:

**`QUICK_START.md`** - Быстрый старт за 30 секунд
- Основные команды
- Примеры
- Советы

**`USAGE_GUIDE.md`** - Полное руководство
- Все способы использования
- Описание моделей
- Алгоритм работы
- Советы для лучших результатов

**`MODELS_CHEATSHEET.md`** - Шпаргалка по моделям
- Сравнение всех моделей
- Когда какую использовать
- Примеры промптов
- Статистика
