# 🎨 Neurophoto Plugin - Руководство по использованию

## 🚀 Как использовать

### ✅ Бот понимает естественный язык!

Не нужно использовать строгие команды - просто опишите что хотите:

#### 🇷🇺 Русский:
```
нарисуй кота в космосе
создай изображение заката над океаном
покажи как выглядит футуристический город
сделай фото уютной кофейни
сгенерируй картинку с драконом
```

#### 🇺🇸 English:
```
draw a dragon flying over mountains
create image of a sunset
show me a futuristic city
can you draw a cat?
make a picture of coffee shop
```

#### 💻 Или используйте команду:
```
/neurophoto описание того что хотите увидеть
```

- **Стиль**: Профессиональный, детализированный

- **Модель**: `stability-ai/sdxl:latest`
- **Скорость**: Средняя (20-40 сек)
- **Качество**: Отличное
- **Стиль**: Стабильный, предсказуемый
- **Когда использовать**: Для классических стилей

### Детальные запросы (лучше результат):

---

## ⚙️ Что происходит когда вы отправляете запрос

1. **Бот распознаёт намерение** 🧠
   - Анализирует ваше сообщение
   - Определяет что вы хотите изображение

2. **Извлекает промпт** 📝
   - Удаляет служебные слова ("нарисуй", "создай")
   - Оставляет только описание

3. **Генерирует изображение** 🎨
   - Отправляет запрос в Replicate API
   - Использует Flux Schnell модель
   - Ждёт 10-30 секунд

4. **Отправляет результат** ✅
   - Показывает изображение
   - Указывает модель которая использовалась
   - Показывает время генерации

---

## 🎯 Советы для лучших результатов

### ✅ Хорошие промпты:
- **Детальные**: "красивый закат над океаном с пальмами, яркие оранжевые тона"
- **Со стилем**: "футуристический город, киберпанк стиль, неоновые огни"
- **С настроением**: "уютная кофейня, тёплый свет, утренняя атмосфера"
- **На английском**: Модели лучше понимают английский

### ❌ Слабые промпты:
- Слишком короткие: "кот", "город", "машина"
- Без деталей: "нарисуй что-нибудь"
- Расплывчатые: "сделай красиво"

## 📊 Информация в ответе

После генерации бот покажет:

```
✅ Изображение готово!

📝 Промпт: закат над океаном
🎨 Модель: Flux Schnell ⚡️
⏱️ Время: 15 сек

Модель AI: black-forest-labs/flux-schnell
```

- **Промпт**: Что было отправлено AI
- **Модель**: Какая модель использовалась (красивое название + emoji)
- **Время**: Сколько заняла генерация
- **Модель AI**: Полный ID модели на Replicate

## 🔧 Технические детали

### Алгоритм работы:

```
1. Пользователь пишет запрос
   ↓
2. validate() проверяет намерение
   - Ищет ключевые слова: "нарисуй", "создай", "покажи"
   - Или прямую команду: /neurophoto
   ↓
3. handler() обрабатывает запрос
   - Извлекает промпт из текста
   - Валидирует (минимум 3 символа)
   ↓
4. ReplicateService генерирует
   - Отправляет в Replicate API
   - model: black-forest-labs/flux-schnell
   - num_outputs: 1
   - aspect_ratio: 1:1
   ↓
5. Результат отправляется пользователю
   - Изображение как attachment
   - Метаданные в тексте сообщения
```

## 🎨 Модель по умолчанию

**Flux Schnell** используется по умолчанию потому что:

1. ⚡️ **Быстрая** - генерирует за 10-20 секунд
2. 🎯 **Качественная** - отличное соотношение скорость/качество
3. 🌍 **Универсальная** - хорошо работает с разными стилями
4. 💰 **Эффективная** - оптимальная стоимость
5. 🇷🇺 **Понимает русский** - может работать с русскими промптами
