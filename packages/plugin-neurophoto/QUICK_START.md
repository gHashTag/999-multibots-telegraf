# ⚡️ Quick Start - Neurophoto Plugin

## 🚀 Быстрый старт за 30 секунд

### 1️⃣ Просто напишите что хотите:
```
нарисуй закат над океаном
```

### 2️⃣ Подождите 10-20 секунд ⏱️

### 3️⃣ Получите изображение! 🎨

---

## ✅ Что работает:

```
✅ нарисуй кота
✅ создай изображение города
✅ покажи как выглядит дракон
✅ сделай фото кофейни
✅ /neurophoto красивый закат
✅ draw a dragon
✅ create image of sunset
```

## 🔧 Если не работает:

1. Проверьте что описание > 3 символов
2. Попробуйте проще: "нарисуй кота"
3. Используйте прямую команду: `/neurophoto кот`
4. Пишите на английском для лучшего результата
