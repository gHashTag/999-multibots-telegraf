# 🎭 LoRA Integration Guide - NEURO_SAGE

## 🎯 Что такое LoRA?

**LoRA** (Low-Rank Adaptation) - это технология, которая позволяет "обучить" AI модель на ваших личных фотографиях, чтобы генерировать изображения с вами в любых ситуациях!

### 🤝 Ваша личная LoRA: NEURO_SAGE

- **URL**: `https://v3b.fal.media/files/b/elephant/YpfnIK7JlNO7vZTsGanfo_pytorch_lora_weights.safetensors`
- **Trigger Word**: `NEURO_SAGE`
- **Размер**: 9:16 (вертикально, идеально для соцсетей)
- **Модель**: Flux LoRA на fal.ai

---

## 🚀 Быстрый старт

### 1️⃣ Настройте .env файл:

```bash
# Выберите fal.ai как провайдер
IMAGE_PROVIDER=fal

# Ваш API ключ fal.ai
FAL_KEY=your_fal_api_key_here

# LoRA настройки (уже настроено)
FAL_DEFAULT_LORA_PATH=https://v3b.fal.media/files/b/elephant/YpfnIK7JlNO7vZTsGanfo_pytorch_lora_weights.safetensors
FAL_DEFAULT_LORA_SCALE=1.0
FAL_LORA_TRIGGER=NEURO_SAGE
```

### 2️⃣ Напишите боту:

```
нарисуй меня на пляже
создай изображение меня в космосе
покажи как я выгляжу в деловом костюме
NEURO_SAGE на фоне заката
```

**Важно**: Триггерное слово `NEURO_SAGE` автоматически добавляется к каждому промпту!

## 🔧 Настройка LoRA Scale

LoRA scale определяет насколько сильно применяется ваша персонализация:

### Scale 0.5 (Слабо):
```bash
FAL_DEFAULT_LORA_SCALE=0.5
```
- Легкое сходство
- Больше вариаций
- Хорошо для экспериментов

### Scale 1.0 (По умолчанию):
```bash
FAL_DEFAULT_LORA_SCALE=1.0
```
- Оптимальное сходство
- Сбалансированный результат
- **Рекомендуется**

### Scale 1.5 (Сильно):
```bash
FAL_DEFAULT_LORA_SCALE=1.5
```
- Максимальное сходство
- Меньше вариаций
- Для точных портретов

## ❓ FAQ

### Q: Зачем нужно триггерное слово?
**A**: `NEURO_SAGE` активирует вашу персонализированную LoRA модель, чтобы AI знал что нужно генерировать именно вас.

### Q: Можно ли убрать триггерное слово из промпта?
**A**: Нет, оно добавляется автоматически и необходимо для работы LoRA.

### Q: Можно ли изменить размер изображения?
**A**: Сейчас фиксированно 9:16 (768x1365). В Phase 2 добавим настройки.

### Q: Сколько стоит генерация?
**A**: ~$0.035 за изображение (768x1365 ≈ 1MP).

### Q: Можно ли использовать свою LoRA?
**A**: Да! Укажите URL вашего .safetensors файла в `FAL_DEFAULT_LORA_PATH`.
