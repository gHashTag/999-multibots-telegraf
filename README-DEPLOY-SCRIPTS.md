# 🚀 Скрипты для быстрого деплоя bot-farm

## 📋 Описание

Набор скриптов для быстрого управления production окружением bot-farm. Позволяет быстро перезапускать, пересобирать и очищать систему.

## 🎛️ Главное меню

### Запуск главного меню:
```bash
bash scripts/deploy-menu.sh
```

**Функции меню:**
1. 📊 **Показать текущий статус** - проверка контейнера, образа и кода
2. 🔄 **Быстрый перезапуск** - перезапуск без пересборки (быстро)
3. 🚀 **Quick Deploy** - пересборка образа с новым кодом
4. ☢️ **Nuclear Reset** - полная очистка и пересборка всего
5. 🧹 **Очистить Docker** - удаление неиспользуемых ресурсов
6. 📋 **Показать логи** - последние 20 строк логов
7. 🔍 **Проверить здоровье** - проверка работоспособности API
8. 🚪 **Выход** - завершение работы

## 🚀 Quick Deploy (пересборка образа)

### Запуск:
```bash
bash scripts/quick-deploy.sh
```

**Что делает:**
- ✅ Проверяет Git статус
- 🛑 Останавливает старый контейнер
- 🗑️ Удаляет старый контейнер
- 🏗️ Пересобирает Docker образ
- 🚀 Запускает новый контейнер
- 🔍 Проверяет здоровье
- 📊 Показывает статус

**Время выполнения:** ~2-3 минуты

## 🔄 Quick Restart (быстрый перезапуск)

### Запуск:
```bash
bash scripts/quick-restart.sh
```

**Что делает:**
- 🛑 Останавливает контейнер
- 🚀 Запускает контейнер
- 🔍 Проверяет здоровье
- 📊 Показывает статус

**Время выполнения:** ~30 секунд

## ☢️ Nuclear Reset (полная очистка)

### Запуск:
```bash
bash scripts/nuclear-reset.sh
```

**Что делает:**
- ⚠️ Запрашивает подтверждение (введите 'YES')
- 🛑 Останавливает все контейнеры
- 🗑️ Удаляет все контейнеры и образы
- 🧹 Очищает Docker систему
- 🗂️ Удаляет node_modules и dist
- 📦 Переустанавливает зависимости
- 🏗️ Пересобирает проект
- 🐳 Пересобирает Docker образ
- 🚀 Запускает новый контейнер
- 🔍 Проверяет здоровье

**Время выполнения:** ~5-10 минут

## 🎯 Когда использовать какой скрипт

### 🔄 **Quick Restart** - когда:
- Контейнер завис
- Нужен быстрый перезапуск
- Код не изменился

### 🚀 **Quick Deploy** - когда:
- Изменился код в production
- Нужно обновить Docker образ
- Проблемы с образом

### ☢️ **Nuclear Reset** - когда:
- Полный сбой системы
- Проблемы с зависимостями
- Нужна полная очистка
- Проблемы с Docker

## 📊 Мониторинг

### Проверить статус:
```bash
docker ps | grep 999-multibots
```

### Посмотреть логи:
```bash
docker logs -f 999-multibots
```

### Проверить здоровье:
```bash
docker exec 999-multibots nc -z localhost 2999
```

## 🔧 Проверка исправленного кода

Все скрипты автоматически проверяют, что Instagram scraper исправлен:

```bash
# Проверка в контейнере
docker exec 999-multibots grep "name: 'instagram/scraper'" /app/dist/services/generateInstagramScraping.js
```

**Ожидаемый результат:**
```javascript
name: 'instagram/scraper',
```

## ⚠️ Важные замечания

1. **Всегда проверяйте Git статус** перед деплоем
2. **Nuclear Reset удаляет ВСЕ** - используйте осторожно
3. **Быстрый перезапуск** не обновляет код
4. **Quick Deploy** обновляет код, но не очищает полностью
5. **Проверяйте здоровье** после каждого действия

## 🚨 Устранение проблем

### Контейнер не запускается:
```bash
# Проверить логи
docker logs 999-multibots

# Проверить переменные окружения
docker exec 999-multibots printenv | grep -E "(NODE_ENV|PORT)"
```

### Образ не собирается:
```bash
# Очистить Docker
docker system prune -f

# Пересобрать с нуля
bash scripts/nuclear-reset.sh
```

### API не отвечает:
```bash
# Проверить порты
netstat -tlnp | grep :2999

# Проверить контейнер
docker exec 999-multibots ps aux
```
