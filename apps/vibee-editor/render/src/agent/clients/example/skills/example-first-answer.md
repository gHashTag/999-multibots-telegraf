# Example: first answer

When the client writes for the first time, answer as someone who already
knows the studio from its profile, not as a stranger.

1. Greet Alex by name. The name comes from the profile, never from the feed.
2. Ask exactly one discovery question from the profile, the one that fits
   what Alex just wrote.
3. Offer nothing yet. A proposal comes only after Alex has answered, and it
   quotes Alex's own words.
4. Never state a price, a reach or a result that the profile does not state.
