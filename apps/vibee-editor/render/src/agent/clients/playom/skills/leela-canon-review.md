# Leela: проверка канона перед выпуском

Прогоняй каждый черновик о Лиле через эти проверки; при расхождении исключай спорное утверждение и помечай вопрос для Геи.

Факты движка (истина — код `gHashTag/leela`, не пересказ):
- 72 плана; вход на поле только с шестёрки → план 6 «Заблуждение (моха)»; победа только точное попадание на 68 «Космическое Сознание (Вайкунтха-лока)»; 72 «Тамогуна» → змея на 51; три шестёрки подряд сжигают серию.
- Змеи: 12→8, 16→4, 24→7, 29→6, 44→9, 52→35, 55→3, 61→13, 63→2, 72→51. Стрелы: 10→23, 17→69, 20→32, 22→60, 27→41, 28→50, 37→66, 45→67, 46→62, 54→68.
- Ряды снизу: 1–9 Муладхара, 10–18 Свадхистхана, 19–27 Манипура, 28–36 Анахата, 37–45 Вишуддха, 46–54 Аджна, 55–63 Сахасрара, 64–72 за пределами чакр. Верхний ряд читается 72…64, 68 в центре без цифры.
- Начальное состояние хранит loka 68 до входа на поле — «68» само по себе не доказательство победы; статус даёт движок.
- Правила задаёт выбранный RuleSet (по умолчанию `classic`); шестёрка даёт дополнительный ход, но не отменяет отчёт после прибытия.

Источники: Harish Johari, «The Yoga of Snakes and Arrows», Inner Traditions 2007 (ISBN 9781594771781). Происхождение игры не датировать; книгу цитировать фрагментами, не перепечатывать.

Стоп-проверки:
- нет цен, скидок, процентов, отзывов, «первый/единственный/лучший», гарантий, предсказаний, диагнозов;
- нет слов давления: отсутствовал, пропал, давно, серия, срочно, сегодня, последний шанс, прогресс, молодец, успех;
- название плана не стало характеристикой человека;
- змея не названа наказанием, стрела — наградой;
- команды бота (/plan, /board, /path) сверены с живым ботом, а не взяты из памяти;
- заявления о работоспособности («бот отвечает», «сохраняет историю») подтверждены проверкой, иначе помечены как непроверенные.
