# Leela: бриф на рил LeelaPlanReel

Единственный шаблон рилс для Лилы — `LeelaPlanReel` (1080×1920, 12 с). Не использовать TrinityBlogReel (гравюра блога t27), PromoReel (фонк) и сгенерированные картинки с текстом.

Порядок:
1. Выбери план: `leela_plan {plan}` → возвращает канон и готовые `reel_props`.
2. Крючок ≤12 слов, одна мысль. Цитата — фрагмент канонического описания (≤220 знаков), не пересказ.
3. Вопрос (необязательно) — один, мягкий, без требования раскрывать личное.
4. CTA по умолчанию: «Здесь нет правильного ответа. Приходите на доску со своим вопросом.» + кнопка «🎲 Играть в Лилу», t27.ai/leela, @leela_chakra_ai_bot.
5. Рендер: `reel_render {compositionId: "LeelaPlanReel", props: reel_props}`; результат описывай только по факту (ссылка на файл), не приписывай ролику того, чего не видел.

Визуальный контракт (не менять): чёрный фон и редкие звёзды; белая паутина доски 9×8 без заливок; кубик точками, никогда цифрой; 68 без номера — Цветок Жизни `#e0b544`; фишка — лотос `#2f5fd0`; змея `#f08a72`, стрела `#5fc684`; шрифт Outfit; зелёный `#00ff88` только на кнопке; золото `#ffd700` только на линии под заголовком.

Серия из 12 роликов (по одному плану): 6 «вход только с шестёрки», порог «68 на старте — ещё не победа», 68, 72→51 «последний номер — не финиш», 12→8, 17→69, 26, 55→3, 63→2, «отчёт — не экзамен», 46→62, групповой стол.
